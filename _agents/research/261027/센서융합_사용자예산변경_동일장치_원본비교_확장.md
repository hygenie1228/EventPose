# 사용자 예산 변경과 동일 장치·원본 비교 확장

## 최신 사용자 지시로 확장한 비교 범위

주표는 원본 RGB3/RGB4 두 조건과 새7학습조건, 총9조건의 동일 공통GT5지표다. 새 학습은 짧은 RGB3/RGB4, RGB3+event4, event3+RGB4, event3+event4, 같은 장치 RGB3+event3, RGB4+event4다. 융합은3시간, RGB-only는90분 예산의 조기 종료다. 원본 모델은 ETRI 미세조정0 update다. 사용자 지시대로 학습량 차이를 둔 비교이며 센서만의 인과 효과로 해석하지 않는다. 학습량별 곡선은 원본·출처 기존학습·이번 선택 checkpoint의 실측값으로 작성하고 개선을 보장하거나 값을 조정하지 않는다.

기존 RGB3는 요청 당시103분을 넘어 진행되어 중단했다. 그룹 종료 신호가 DataLoader worker도 종료해 최종 추가 저장 전에 예외가 발생했고, 주기 checkpoint2,013 update를 실제 로드·유한값 검사·288 holdout 재검증으로 복구했다. 종료 직전 관측2,050 update 대비 최소37 update는 보존되지 않았다. 복구 PA는23.8966mm이며 Test 결과가 아니다. 이 run은 참고·실행 이력으로 그대로 보존한다. 본 비교 RGB3는 별도 `rgb3_short90` 독립90분 trial로 정확한 카운터를 확보한다. 기존 중단 run을90분 결과로 표시하거나 덮어쓰지 않는다.

RGB4의 첫90분 설정은 기존 최소3시간 assert로 CUDA 학습 전에 실패했다. 원래3시간 스케줄을 유지하고 per-trial 마감으로90분에 조기 종료하도록 수정했다. 첫 실패 launch 시각도 budget에서 제외하지 않으므로 실제 활성 학습 시간은90분보다 짧을 수 있다. 실제 update·샘플·선택 checkpoint 경과 시간을 별도 보고한다. 융합 세 작업은 중단하지 않았다. 종료 보호는 trainer 부모에 먼저 SIGTERM을 보내 저장한 뒤 종료하도록 보강했다.

같은 장치 두 조합과 원본 두 조건은 실제 CPU 초기화 및 입력 parity·원본 출처 검증을 통과했다. 기존 모델 경로는 AST를 대조해 계산 변경이 없음을 확인했으며 새 센서 조합 dictionary와 별도 원본 loader만 확장했다. phase별 실제 source snapshot/hash를 보존하고 최종 감사에서 승인된 두 버전을 각각 대조한다. Test 전에13개 통계 비교쌍과9조건 공통GT·장치별 학습곡선 공통GT를 고정했다. 한국시간2026-10-28 04:15:31 마감은 유지한다.
