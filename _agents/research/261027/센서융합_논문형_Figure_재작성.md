# 논문형 Figure 재작성

사용자 지정 Multi-HMR 논문3페이지 Figure2를 실제 렌더링해 확인하고 가로 흐름의 새 구조도를 작성했다. 긴 설명형 상자를 제거하고 RGB·event 입력, ViT, residual fusion, patch detection, human queries, HPH, SMPL-X mesh를 표시했다. 전체 token의 K/V 경로 및 주 특징 query→ray attention 경로를 표시했다. 보조 event 분기는 주황색으로 구분했다. 실제 고정 Train 초기화 모델의 검출 score와 mesh를 CPU에서 추론해 예시로 사용했고 GT를 추론 입력으로 사용하지 않았다. 이 예시는 새 본학습 성능이나 Test 시각화가 아니다. 원본 도식을 복사하지 않고 배치 형식을 참고했으며 보고서에 논문을 인용했다. SVG·PDF·PNG의 SHA256 및 모든 보고서 링크를 검증했다. 기존 상세 그림은 산출물로 보존하고 본문은 새 단일 Figure 중심으로 교체했다.
