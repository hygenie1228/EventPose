# 중간 checkpoint의0입력 잔차 분해

## 0입력 스트레스 검사의 잔차 분해

동일한 불변 중간 checkpoint와 Train 프레임으로 CPU 계산을 반복해 앞선 예측·오차가 정확히 재현되는지 확인했다. 정상 event 입력의 잔차/주특징 L2는 RGB3+event4 3.94%, event3+RGB4 5.12%, event3+event4 3.06%였다. event tensor를0으로 바꾸고 가용성 플래그를1로 유지하면 각각91.95%,80.89%,19.09%로 커졌다. 따라서 이 입력 변형에서는 단순히 event 정보를 덜 쓰는 것을 넘어 주 특징을 크게 바꾸고 있었다. 실제0입력 분포 밖 민감성으로 기록하며 정상 입력에서의 개선 근거로 삼지 않는다.

Linear 출력의 bias 성분 L2와 전체 Linear 출력 L2 비는 각각0.621,0.284,0.418이었다. 이는 공간 mask·upsampling 전 값이며 두 성분이 직교하지 않아 오차 기여율이나 에너지 비율로 해석할 수 없다. CNN/정규화/attention/Linear를 통과한0입력의 특징은0이 아니며, 특정 층 하나의 인과 효과까지 분리한 검사는 아니다. 별도 가용성 플래그가0이면 잔차가 꺼지는 경로와 구분한다.

고정 Train subset에는 global 완전0 event 입력이 없었고, 현재 검사는 한 프레임의 인위적0입력이다. 정상 데이터에서의 열화 원인이라고 단정하거나 이 검사 때문에 진행 중 trial의 architecture·입력 정책·예산을 바꾸지 않는다. 전체 holdout ablation에서 범위와 검출률을 확인하고 이 취약성도 최종 한계에 포함한다. 근거: `first_holdout_snapshot_Train_ablation_components.json`.
