# 오래된 채팅 표시 제한

사용자 요청에 따라 Chat과 AI Agent 모두 오래된 채팅을 화면에서 숨겼다. 목록에는 최근 생성된 채팅 10개를 표시하며, 현재 선택한 채팅과 실행 중인 채팅 및 활성 Goal 채팅은 유지한다. 대화 본문은 최근 메시지·도구 블록 60개만 렌더링하고 브라우저의 이벤트 보관은 최근 300개로 제한한다. 기존 서버 기록과 모델 대화 문맥은 삭제하거나 변경하지 않았다.

서버 API의 전체 기록 응답과 서버 저장 방식은 이번 변경 범위에 포함하지 않았다. 따라서 이번 조치는 주로 브라우저의 반복 렌더링과 화면 요소 누적을 줄인다. 서버를 재시작하지 않고 프런트엔드를 빌드하여 반영했다. 페이지 새로고침 후 적용된다.

검증: 빌드 성공. 실제 로컬 서비스에 연결한 Chromium에서 대화 목록 100개와 이벤트 10000개를 모의 응답으로 주입했다. Chat 및 AI Agent 각각 최근 목록 10개와 오래된 실행 중 채팅 1개, 본문 60개, 최신 답변 보존을 확인했다. 브라우저 예외는 없었다. dataset/ 및 data/는 변경하지 않았다.
