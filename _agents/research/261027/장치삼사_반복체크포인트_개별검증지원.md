# 반복 체크포인트 개별 검증 지원

`tools/audit_device34_repeat_checkpoints.py`는 기본 실행에서 기존 앞 네 조건 검증을 유지하며, `--condition`으로 완료된 조건 하나를 검증할 수 있게 했다. 남은 조건이 끝났을 때 불필요하게 앞 네 조건을 다시 로드하지 않기 위한 변경이다. 실행 중인 학습이나 설정은 수정하지 않았다.

각 best/last의 실제 CPU 로드, 구성 일치, 학습 시간 4시간 미만·설정 3시간·seed, 유한 가중치, Test 미선택, best 평가 step 일치, last 최종 카운터 일치를 검사하며 실제 파일 SHA256을 함께 저장한다. 개별 검증 결과 파일명을 조건별로 분리해 기존 네 조건 감사 결과를 덮어쓰지 않는다.

변경 후 `--help`와 실제 `--condition rgb3` 실행을 확인했다. 후자는 Goal 등록 프로세스에서 실제 두 체크포인트를 읽어 정상 종료했고 `rgb3_seed261027_checkpoint_cpu_audit.json`의 두 파일 해시와 통과 기록을 확인했다. 완료하지 않은 조건은 검증됐다고 주장하지 않는다. 다음 정기 점검에서 남은 학습의 종료 여부를 먼저 확인한다.
