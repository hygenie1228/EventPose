# 전체 Test 발표용 다섯 지표 그림 검증

첫 실험 seed261026의 검증된 `comparison.json`에서 공통 GT 21,659개의 6조건×5지표 점추정치만 읽어 그림을 생성했다. 내부 검증과 반복 실험 수치를 혼합하지 않았다.

- `tools/finalize_device34_body.py::metric_figure`를 추가해 최종 보고서 생성 시에도 같은 그림을 유지한다. 실제 생성 실행을 Goal 관리 프로세스로 등록했고 정상 종료했다.
- `metric_figure_provenance.json`에 조건 순서, 다섯 지표 이름, 30개 실제 입력 수치, 공통 표본 수, split SHA256, seed와 PNG/SVG 경로를 저장했다. 30개 수치 전부 원본 공통 집계와 정확히 일치함을 실행 중 assert로 확인했다.
- `visualizations/전체Test_여섯조건_다섯지표.png`를 실제 열어 한글, 조건 순서, 다섯 패널, 표시 수치, 단위, 범례 성격의 설명과 배치를 확인했다. SVG도 같은 figure에서 내보냈다.
- 각 지표는 0에서 시작하는 독립 가로축이다. 패널 사이 축 범위가 다르므로 패널 사이 막대 길이보다 표시 수치로 비교하도록 보고서에 명시했다. 각 패널의 최소값을 반올림 전 수치로 선정해 굵게 표시했다.
- 점추정 그림은 통계적 유의성이나 후속 반복 성공을 주장하지 않는다. CI/Holm 및 학습 범위·모델 비대칭·GPU 장애 제한은 보고서 본문에 별도로 남겼다.
- 기존 보고서의 실제 예측 시각화, 장애 기록, 주표, 진행 갱신 영역은 보존했다. 전체 Goal은 아직 미완료다.
- 그림 삽입 후 별도의 등록된 CPU 프로세스에서 실제 보고서 본문에 `verify_main_table`과 `verify_supporting_tables`를 실행했다. 6×5 주표와 보조지표·통계·학습 예산 표 검사가 모두 통과했고, 그림의 30개 수치도 원본과 다시 대조해 정상 종료했다. 이는 첫 실험 보고서 검사이며 반복 실험·속도·최종 Goal 완료 검사를 대체하지 않는다.
