# 이벤트 대비 보정과 드라이버 대기

## 실제 Train 진단과 입력 대비 보정

기존 checkpoint를 실제 고정 Train 한 프레임에서 진단했다. 보조 분기가 더하는 특징의 L2 크기는 원래 특징 대비 RGB3+event4에서0.1831%, event3+RGB4에서0.05481%, event3+event4에서0.05373%였다. gate는 초기0.04743에서0.04747~0.04755 수준에 머물렀다. 실제 event와 0 입력 사이 예측 차이도 작았다. 이는 한 프레임의 진단이며 전체 Test 열화의 인과효과나 새 방법 성능으로 해석하지 않는다. 원시 근거는 `legacy_fusion_Train_diagnostic.json`이다.

고정 Train 6,501프레임 전부를 조사했을 때 global event 입력이 완전히 빈 프레임은 두 센서 모두0개였다. GT 투영 body 영역의 활성 픽셀 비율 중앙값은 event3 59.71%, event4 63.02%이며, 완전히 빈 영역은 각각0개와1개였다. GT 영역은 분석에만 사용하고 모델 입력 crop에는 사용하지 않는다. 저장 event 프레임의 활성 픽셀 수이며 원시 개별 event 수가 아니다.

두 센서의 전체 Train 비영 encoded pixel 중앙값은32/255였다. 이 통계만으로 중앙값을0.5에 가깝게 하는 가장 가까운 2의 거듭제곱 gain4를 고정했다. 새 event encoder/refiner에 gain4와 GroupNorm을 적용하되 warmstart projection 경로의 원래 스케일은 보존한다. 정규화 통계 파일·Train index·split SHA256을 새 설정에 묶었다. Test와 holdout을 정규화 선택에 사용하지 않았다. 모든 GPU trial 시작 전 수정한 구조이며, 앞선 CPU 초안은 `prototype_v1_cpu/`에 보존했다. 이 변경의 실제 개선 여부는 아직 미평가다.

2026-10-27 06:04 UTC 재검사에서도 물리1·2·4·5 모두 CUDA 초기화 실패였다. 새로운 GPU pilot·본학습·Test 결과는 없다. 현재 CPU에서 실제 모델 초기화, 합성 geometry/gradient, 실제 holdout 한 프레임의 네 가지 입력 제거 검사까지 통과했다. GPU 복구 후에야 실제 GPU pilot과 본학습을 시작할 수 있다. 고정19:15:31 UTC 마감은 그대로다.
