# 집계·통계·속도 측정 규칙 고정



새5조건 공통 GT와 기존/새10실행 공통 GT를 분리하고, 자기 조건 표본·사전 지정9쌍의 공통 표본도 별도로 집계하도록 구현했다. 모든 원시 예측의 source frame·체크포인트·보정 평가 규칙·미검출 NaN과 전체 GT 처리 여부를 확인하고, 주표 다섯 지표는 SciPy proper rotation 구현으로 독립 재계산해 기존 SVD 계산과 대조한다. 피험자/세션 단위 bootstrap10,000회와 PA/3D root 각9쌍의 Holm 보정, 고정 GT 동작속도 구간 분석 규칙을 `analysis_protocol.json`으로 고정했다. 현재 새 Test 결과가 없어 통계 수치는 아직 계산하지 않았다.

속도 측정은 정상·유휴인 같은 물리 GPU UUID에서 새5조건×캐시/온라인10개를 순차 실행하도록 구성했다. 미리 고정한 Test3세션×100프레임에서 입력 열기·인코딩/캐시I/O·원본 디코드·검출·복원·좌표변환·매칭·저장·닫기를 포함하고, 모델 로딩·host/GPU 메모리·입력 parity 검사는 별도로 기록한다. 실제 GPU 속도 측정은 아직 미실행이다.

auxiliary 도구는 tools/에 두고, 학습과 정상 추론 구현은 scripts/ 및 src/multihmr/에 유지했다. 새 결과를 생성한 것은 아니며 실측과 최종 감사가 남아 있다.
