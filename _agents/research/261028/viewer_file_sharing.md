# Viewer 파일 URL 공유

Viewer에서 파일을 열거나 탭을 바꾸면 브라우저 주소의 file 쿼리 매개변수에 해당 경로를 반영한다. Viewer 도구 모음에 공유 버튼을 추가하여 현재 파일을 여는 URL을 복사한다. 파일 URL로 직접 접속하거나 새로고침하면 해당 파일을 우선 열며, 기존 마지막 파일 복원보다 우선한다. 모든 Viewer 탭을 닫으면 file 매개변수를 제거한다.

복사한 링크에는 로그인 비밀키와 URL 해시를 넣지 않는다. 기존 로그인과 파일 접근 권한을 유지하며, 로그인하지 않은 사용자는 로그인 후 요청한 파일을 연다. HTTPS Clipboard API가 없는 HTTP 환경에는 복사 대체 경로를 제공한다. 한글·공백·특수문자 경로는 URLSearchParams로 인코딩한다. 기존 Chat, AI Agent의 파일 링크도 같은 Viewer 열기 경로를 사용한다.

검증: 프런트엔드 빌드 성공. 실제 로컬 서비스와 Chromium으로 1440px 데스크톱 및 390px 모바일에서 실제 한글 보고서 직접 열기, 주소 갱신, 공유 링크 복사, HTTP 복사 대체 경로, 한글·공백·&·# 경로 왕복, 새로고침 복원, 탭 전체 닫기 후 URL 정리를 확인했다. 로그인 화면을 거쳐 요청 파일을 여는 흐름도 모의 로그인 응답으로 검증했다. 특수문자 이미지 경로는 URL 처리 검증용 가상 경로이며 실제 이미지 내용 검증과 구분한다. 테스트 코드는 src/apps/research-workbench/test/viewer-share.mjs다. 외부 사용자 단말 접속은 검증하지 않았다.

서버 재시작 없이 정적 화면 자산을 반영했으며 dataset/ 및 data/는 변경하지 않았다.
