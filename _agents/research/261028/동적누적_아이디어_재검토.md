# 동적 누적 아이디어 재검토

2026-10-28 한국시간. 사용자 지적: RGB 간헐 추론+event 보정은 시스템 구성 수준이며 dynamic aggregation 같은 구체적인 새 방법이 필요함.

- 핵심을 관절/부위별 이벤트 집계 모듈로 재정의했다. 부위 이동 정렬 후, 과거 관측 추가가 GT 자세 오차를 줄이는지를 Train에서 효용 지도로 만들어 추론용 gain head를 학습하고 부위별 집계를 종료하는 제안이다.
- ASTW, EvHuman, APP, MASC-Pose를 웹 검색으로 검토했다. 일반 적응 창·motion compensation·pose-aware sampling 각각은 기존 요소이며 그 자체를 신규성으로 주장하지 않는다.
- 새 학습·Test·GPU 작업을 실행하지 않았다. 기존 예비결과는 동기로만 쓰고 새 방법 성능으로 사용하지 않는다.
- 보고서: `_agents/report/261028_자세정보이득_기반_관절별_이벤트_동적누적_제안.md`.

- 사용자가 그림과 추론 시 자세 모호성을 아는 방법을 질문했다. 실제 모호성을 안다는 가정을 철회하고, GT 기반 오차 감소 지도와 GT 없는 gain 예측을 분리한 학습/추론 개념도를 생성했다.
- 33→100ms의 이득이 음수여도 더 긴 과거의 이득은 양수일 수 있으므로 단순 greedy 종료가 보장되지 않음을 수정했다. 처음에는 유한 후보를 비교하며 조기 종료는 별도 검증 대상으로 둔다.
- 그림은 matplotlib으로 생성한 방법 개념도다. 실제 결과·실제 confidence·신규 학습을 표현하지 않는다.

- 사용자 요구: 파이프라인 그림이 아니라 예시 그림을 보고서에 넣고 dynamic aggregation의 철학을 드러낼 것.
- 보고서 첫 절을 “시간을 채우는 대신 현재 신체 부위의 증거를 모은다”로 재구성했다. 부위별 과거 범위·이동 정렬·관측 선별을 구분하고 고정 신체부위 규칙이 아님을 설명했다.
- 설명용 장면 삽화와 가상 GT 오차 예시를 추가했다. 실제 센서/예측 결과가 아니라는 표시를 그림 및 본문에 넣었다. pipeline 그림은 보고서 본문에서 제거했다. 기존 파일은 보존했다.
- 완전 정지에서는 누적을 늘려도 새 정보가 생기지 않으며 기억과 관측을 분리해야 함을 명시했다. 새 성능 실험은 하지 않았다.

## 실제 예시와 FPN 설계 및 사용자 운동량 기준 반영

- 사용자 요구를 반영해 실제 원본 두 세션의 동일 시각 RGB와 10/33/100/200ms CSR 관측 누적을 새로 렌더링했다. 가상 예시 그림은 보고서 본문에서 제거했다.
- 전신 11.982초의 팔/몸통과 상체 4.993초의 머리/가슴 관측을 비교했다. 원본 라벨 19시점씩으로 부위별 영상 경로 길이를 계산했다. 10ms 값은 약30Hz GT 궤적의 선형 보간임을 명시했다.
- 핵심을 작은 부위 운동량→긴 창, 큰 부위 운동량→짧은 창으로 정리했다. 현재 속도만이 아니라 구간 누적 경로 길이로 변화량을 정의해 정지 직전 이력을 잘못 끌어오는 문제를 설명했다.
- 공간 FPN과 시간 피라미드를 분리한 논문 형태 구조도를 삽입했다. 입력 4조각×2채널, 공간 P2~P5, 부위 정렬, 예측 운동량 gate, body22 출력이다. 구조도는 제안이며 실제 동적 모델 결과가 아니다.
- 실제 자료·PNG·로컬 링크·원본 stat·인과적 시각·운동량 선택 규칙을 검증했다. 새 신경망 학습이나 기존 GPU 진행 점검은 하지 않았다.

## 다리 ROI 수정

- 사용자 지적에 따라 전신 예시의 비교 영역을 몸통 아래쪽에서 실제 오른쪽 무릎~발목(관절 5,8)으로 변경했다. 새 GT 투영 bbox로 원본 이벤트 누적 그림을 다시 만들고 활성 비율·GT 경로 길이를 재계산했다. 이름만 바꾼 것이 아니다.
- 보고서의 팔/다리 비교 제목·해석·활성도 표·이동량 표·설명용 시간창 선택을 새로운 수치에 맞춰 수정했다. 일반적인 공간 FPN 설계는 유지했다.

## 넓은 ROI와 Transformer 중심 설계 반영

- 사용자 지적: ROI가 너무 작고 작업을 부분 수정으로 끝냄. 양쪽 다리 전체를 골반~발, 양팔 전체를 최근 위치의 합집합과 여유 공간으로 확장했다. 다리 영역 44×135에서 238×338, 약13.5배로 확대하고 별도 큰 4열 비교 그림을 추가했다. 팔·다리 표와 이동량 관절 집합도 함께 수정했다.
- 추가 사용자 지시: FPN 중심 대신 Transformer 사용. patch tokens→시간별 독립 공간 Transformer→관절 queries→motion-conditioned temporal cross-attention→3D joints로 설계를 변경했다. 기존 FPN 구조 그림은 보존하되 보고서에서는 새 Transformer 그림으로 교체했다.
- 중요한 설계 점검: 시간 gate 앞에서 과거를 무제한 섞지 않도록 encoder는 구간별 공간 attention만 한다. 시간 결합은 관절별 gate가 적용된 cross-attention에서 수행한다. 이후 joint self-attention/이전 상태의 간접 과거 의존성과 직접 token 접근 제한을 구분했다.

## 패치별 constant-count 우선안

- 사용자가 RGB 질의 시각 이전 패치/픽셀별 고정 이벤트 수 누적을 제안했다. motion head 없이 관측량에 따라 누적 기간이 달라지는 강한 단순안임을 인정하고 보고서 첫 절에 우선 검증 대상으로 넣었다.
- 최대 이력·관측 부족 마스크·실제 관측 시각을 유지하고, 픽셀별 발생률이 신체 부위의 속도와 같지 않음을 구분했다. 저장 CSR 활성 관측은 원시 이벤트 수가 아니며 프레임 안 순서가 없으므로 N 초과 마지막 프레임 처리 규칙을 명시했다.
- DHP19/ASTW 원 논문 공개 검색본을 재확인했다. 기존 motion-conditioned Transformer는 단순안을 넘어설 필요가 입증된 뒤의 확장 후보로 낮췄다. 새 성능 실험은 하지 않았다.

## noise 누적과 예시 B에 대한 해석

- 사용자가 noise 누적 때문에 learning 방식이 더 적절하며 예시 B가 이를 보여준다고 지적했다. 단순 count는 기준선, 주안은 제한된 후보의 학습된 신뢰도 가중 집계로 정리했다.
- 예시 B는 count와 유효한 정보량이 같지 않다는 동기를 뒷받침하지만 모든 점의 noise 여부나 learning 우월성을 증명하지는 않는다. 원본에 실제 noise 정답이 없는 점을 명시했다.
- Transformer 관측 신뢰도 head, query 관련성, 최대 후보/이력, null token/기억 fallback을 설계에 추가했다. softmax가 전부 나쁜 후보도 반드시 선택할 수 있는 문제를 명시했다. 실제 noise 확률이라는 주장은 하지 않는다.
- 기존 운동량 gate 구조는 추가 절제실험 후보로 유지하고 새 신뢰도 학습형 구조도를 보고서에 추가했다. 새 학습이나 noise 성능 실험은 아직 없다.
