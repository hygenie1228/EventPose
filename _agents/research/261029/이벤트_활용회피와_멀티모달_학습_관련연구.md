# 이벤트 활용 회피와 멀티모달 학습 관련 연구

작성: 2026-10-29 한국시간. 본 노트는 실제 v1 실패 진단 뒤 v2 학습 정책을 해석하는 문헌 근거다. 원문 출판사 PMLR 초록과 CVF 공식 검색 결과를 확인했다. 아래 연구가 우리 Transformer 회귀 모델의 실패를 직접 증명한다는 주장은 하지 않는다.

[Wu et al., ICML 2022, Characterizing and Overcoming the Greedy Nature of Learning in Multi-modal Deep Neural Networks](https://proceedings.mlr.press/v162/wu22d.html)은 한 modality에 의존하면서 다른 modality를 충분히 학습하지 못하는 현상을 다루고, 추가 modality의 조건부 이용도와 학습 속도로 진단한다. 우리 실험의 intact/zero/shuffle 개입과 연결되는 문제의식이다. 본 논문의 수식·알고리즘을 그대로 구현한 것은 아니다.

[Huang et al., ICML 2022, Modality Competition](https://proceedings.mlr.press/v162/huang22e.html)은 특정 단순화된 분포와 late-fusion ReLU 네트워크 조건에서 modality 경쟁을 분석한다. 제한된 가정의 이론이므로 우리 ViT+MLP 집계의 null 붕괴가 같은 원리라고 단정할 수 없다.

[Peng et al., CVPR 2022, Balanced Multimodal Learning via On-the-Fly Gradient Modulation](https://openaccess.thecvf.com/content/CVPR2022/html/Peng_Balanced_Multimodal_Learning_via_On-the-Fly_Gradient_Modulation_CVPR_2022_paper.html)은 modality 사이 최적화 불균형을 다룬다. 따라서 warmup·학습 균형 조정 자체를 새로운 기여로 내세우지 않는다.

현재 우리가 직접 관측한 것은 v1의 이벤트 선택 질량이 약7.7e-6이고, 고정 holdout에서 이벤트를 지우거나 섞어도 PA 오차 차이가 약0.002mm 이하라는 사실이다. 이벤트 자체가 이 조건에서 덜 유용한지, 최적화가 어려운지, 공간적 혼입이 원인인지 아직 분리하지 못했다. v2는 bias-free 출력·공간 support·시간 gate warmup을 같은 global/part 대조군과 비교해 이 가설들을 검증한다. 더 많은 이벤트 사용량 자체를 성능 성공으로 해석하지 않는다.
