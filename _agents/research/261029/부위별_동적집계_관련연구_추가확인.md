# 부위별 동적 집계 관련 연구 추가 확인

작성: 2026-10-29 한국시간. 공식 CVF 검색 색인과 IEEE DOI 초록으로 확인했다. CVF 직접 열기는403으로 실패했으므로 상세 수식과 구현 차이를 원문 검증했다고 주장하지 않는다.

- [ASTW, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Sui_Adaptive_Spatial-Temporal_Window_Unlocking_the_Potential_of_Event_Cameras_in_CVPR_2026_paper.html): 공간·시간 적응형 창과 이질적인 속도를 다루는 기존 연구가 존재한다. 적응형 시간 집계 자체의 최초성을 주장하지 않는다.
- [EVT, WACV 2025](https://doi.org/10.1109/WACV61041.2025.00500): 인스턴스별 영상 특징에 이벤트 특징을 결합하고 인체 관계와 시간 Transformer를 사용해3D 자세를 추정한다. RGB+event Transformer 자체의 최초성을 주장하지 않는다. 부위별 집계 대조군이 필요하다.
- [EvHuman, ICCV 2025](https://www.openaccess.thecvf.com/content/ICCV2025/papers/Wang_Continuous-Time_Human_Motion_Field_from_Event_Cameras_ICCV_2025_paper.pdf): 이벤트에서 연속시간 인체 모션 필드를 예측한다. 본 설계는 RGB 질의 시각의 부위별 이벤트 선택에 집중한다는 검증 가능한 차이를 설명해야 한다.

우리 방법의 기여 후보는 다음 세 조건을 실측으로 함께 만족하는지에 있다. (1) 같은 장치의 보정된 RGB 조건부 부위 query가 관측 기간을 선택한다. (2) candidate memory가 같을 때 global dynamic보다 part dynamic이 낫다. (3) 부위별 가중치가 원본 이벤트에 반응하고 zero/shuffle 진단에서 성능 변화가 보인다. 아직 학습된 결과가 없어 기여의 유효성은 미검증이다.
