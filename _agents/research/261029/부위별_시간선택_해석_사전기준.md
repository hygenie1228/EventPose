# 부위별 시간 선택 해석 사전 기준

작성: 2026-10-29 한국시간. 본학습 결과 확인 전의 해석 기준이다. 데이터 산출은 전담 data_memory helper가 담당하며 이 문서는 별도 수치 산출을 하지 않는다.

## null과 관측 나이 분리

모델의 부위 p 시간 가중치를 w[p,b], null 선택을 w_null[p]라 한다. 이벤트 사용 질량은 q[p]=sum_b w[p,b]=1-w_null[p]다. 시간 구간 중심은 최근부터16.5,66.5,150ms다. 이벤트를 선택했다는 조건의 명목상 구간 나이는 sum_b(w[p,b]*center[b])/q[p]로 계산한다. q가0에 가깝다면 조건부 나이는 미정 또는 별도 저사용 그룹으로 표시한다.

null을0ms로 취급해 가중 평균을 내면 이벤트를 무시할수록 최근 관측을 골랐다는 잘못된 해석이 생긴다. 따라서 이벤트 사용 질량과 조건부 나이를 항상 함께 보고한다. 중심값 기반 나이는 실제 각 이벤트의 가중 평균 시각이 아니라 구간 기반 proxy임을 명시한다.

## 실제 운동과의 관계

GT는 진단에만 사용한다. 좌표계와 운동 정의를 명시하고 같은 query의 부위와 비교한다. Event camera에 투영한 관절의200ms 경로 길이는 관측 면의 운동과 관련되며, 단순 두 끝점 차이는 왕복 운동을 놓칠 수 있다. 전신 이동이 이벤트를 발생시키므로 root-relative3D운동만으로 관측면의 운동을 대표한다고 주장하지 않는다. 필요한 경우 둘을 구분한다.

6부위×288 query가 독립 표본1728개라는 가정은 하지 않는다. 피험자/세션별 기술통계와 사례 또는 cluster 기반 불확실성을 사용한다. 느린다리·빠른팔의 특정 장면만으로 일반적 법칙을 확인했다고 주장하지 않는다.

정확도 개선 없이 시간 가중치 그림만 그럴듯한 경우에는 방법의 성공으로 판정하지 않는다. 부위별 선택은 같은 memory를 사용하는 전신 공통 선택과 비교한다.
