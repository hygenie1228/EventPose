# 부위별 동적 집계 구현·실행 인계

작성: 2026-10-29 한국시간. 원본 데이터와 data 자산은 읽기전용으로 유지한다.

## 구현

`src/multihmr/part_aggregation_model.py`는 Multi-HMR의 RGB ViT 출력에 residual을 더하는 구조다. 공간 token에서 여섯 부위 query가 RGB 문맥을 읽고, 동일 device3의 3개 과거 이벤트 구간을 patch embedding 및 공유 공간 Transformer로 표현한다. RGB ray를 여러 양의 깊이에서 event camera로 보정 투영한 뒤 깊이별 matching·부위별 시간 선택·null 선택을 분리한다. 각 부위의 시간 선호를 RGB 공간 token으로 전달한다. FPN은 사용하지 않는다.

RGB-only는 이벤트 파일을 읽지 않으며 같은 RGB adaptation 경로와 부위 보조손실을 사용한다. 고정 3구간 균등 집계는 200ms 원시 count 단일 표현이 아니다. 전신 동적 집계는 같은 여섯 query 및 시간 후보를 유지하고 시간 가중치만 부위에 공통으로 적용한다. 부위 query의 약한 공간 지도는 학습 손실에서만 GT를 읽는다. 추론 입력 whitelist에 GT는 없다.

최종 forward는 `calibrated_part_temporal_transformer_v1`로 동결했다. config의 `model_source_sha256`을 빌드 시 검사한다. 모델·데이터·학습·평가·지표·런처·관리 코드의 소스 snapshot과 해시를 실험 폴더에 보관했다. 이후 후보는 config hyperparameter만 바꾼다.

## 실측 초기 검증

네 조건의 실제 CUDA 8-step pilot을 물리 GPU1·2·4·5에서 각각 실행했다. 모두 8/8 성공 업데이트와 해당 step의 검증/체크포인트를 생성했다. 이벤트 조건의 encoder gradient와 동적 조건의 time-score gradient가 양수다. 제안 모델의 최대 encoder gradient는 약 0.02754, time-score gradient는 약 0.00984였다.

8-step 소규모 Train-holdout 진단에서 동적 조건의 null 비중이 약 91%다. 이것을 이벤트 유용성의 증거로 해석하지 않는다. 본학습 후 같은 frozen checkpoint의 intact/zero/missing/shuffle/reverse 입력을 Train-holdout 288프레임에서 진단한다. 실제로 이벤트를 무시하는 해가 나오는지도 별도로 보고한다.

## 지속 실행

설정은 `part_aware_dynamic_aggregation_goal_20h.json`, 출력은 `exp/261029/part_aware_dynamic_aggregation/`이다. CPU4worker가 78개 body 세션의 causal memory를 생성한다. 이벤트 끝은 실제 RGB3 시각이며 공통 GT 시각보다 늦은 이벤트를 사용하지 않는다. 최신 RGB3와 GT의 약 33ms 이내 차이는 모든 조건에 공통이다.

관리기는 `tools/run_part_aggregation.py`, 실행 신원은 출력의 `scheduler_launch.json`과 `managed_jobs.json`이다. 초기 pilot 이후 전체 Train/holdout memory 준비가 끝나면 자동으로 본학습한다. 본학습 조건은 최대 3,000 성공 업데이트·3시간 상한이며 비교 조건끼리 동일하다. 추가 단계는 primary → validation 후보 → seed2 → 추가 학습 예산 비교 → seed3이며 시간 부족 조건은 명시적으로 건너뛴다.

제안 모델의 본학습이 끝나면 이벤트 개입 holdout 진단을 우선 실행한다. 주표는 18개 Test 피험자·80개 10초 구간·24,080프레임의 전체 Test만 사용한다. 첫 프레임/프레임별 MPJPE·PA-MPJPE 및 RPE-Z를 같은 공통 검출 GT 표본에서 계산한다. RPE-Z는 3D norm이 아닌 pelvis Z 절대 오차다. 검증으로만 checkpoint·후보를 선택하고 Test로 방법을 수정하지 않는다.

새 본학습 checkpoint는 실험별 `.experiment_storage/part_aggregation_261029/checkpoints/` SSD backing에 저장하고 exp의 조건 폴더에서 symlink로 연결한다. 이 backing은 활성 작업 동안 보존한다. 최초 pilot은 원래 NFS 경로에 남긴다.

고정 마감은 2026-10-30 09:55:12 KST다. 학습 worker 자체 마감·관리기·독립 guard thread가 본인 등록 작업만 종료한다. 마지막 2분은 체크포인트 보존과 검증을 위한 종료 구간이다. 관리기는 마감 시각까지 유지되며 결과와 미완료 조건을 남긴다. Native Goal 완료 판정은 root가 최종 결과를 검증한 뒤 수행한다.

직접 장기 학습/평가 조회는 30분 간격으로만 한다. 자동 관리자와 보고서는 토큰 없이 동작한다. Root의 다음 직접 조회 예약은 별도 시작검증 노트에 기록되어 있다.
