# 부위별 동적 집계 구현 구조도

작성: 2026-10-29 한국시간.

현재 `PartTemporalAggregation` 구현의 여섯 부위 query, 세 비중복 과거 구간, 공유 spatial Transformer, 보정 ray/depth matching, null 포함 시간 가중치, RGB residual 및 Multi-HMR pose head를 도식화했다. 기존 아이디어 단계의 joint-wise cross-attention 그림 대신 실제 구현의 부위별 시간 분포를 RGB 공간 token에 전달하는 방식을 표현했다.

예시는 Training 세션 `20260720_131207_863008_200_b`의 실제 device3 RGB와 동일 시각 이전 native CSR 관측이다. 원본 event counts로 고정 밝기·극성 색상과 동일 약한 공간 지지를 적용했다. GT는 충분히 큰 인체 표시 crop을 정하는 데만 사용했다. 모델이 GT crop을 입력받는 의미가 아니다. 모델 예측이나 학습된 weight처럼 보이는 가짜 행렬은 넣지 않았다.

PNG를 직접 확인했고 SVG 문구가 영어인지 검사했으며 PDFinfo와 원본 RGB/event/label stat 보존을 검증했다. 구조도와 검증증거는 `exp/261029/part_aware_dynamic_aggregation/figures/`에 저장했다. 재현 도구는 `tools/render_part_aggregation_architecture.py`. 보고서 편집은 전담 agent가 소유하므로 그림 삽입을 메시지로 인계했다.
