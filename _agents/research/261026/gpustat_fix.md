# GPUSTAT 표시 복구

왼쪽 아래 GPUSTAT이 비어 있던 원인은 GPU 3번(PCI 0000:61:00.0)의 NVIDIA 드라이버 오류다. 전체 장치를 한 번에 조회하는 nvidia-smi가 실패해 GPU API가 HTTP 500을 반환했고, 화면에서는 오류를 툴팁에만 기록해 내용이 비어 보였다.

전체 조회 실패 시 /proc/driver/nvidia/gpus의 장치 목록으로 개별 조회하도록 수정했다. 정상 장치는 계속 표시하며 실패 장치는 드라이버 오류 행을 표시한다. API 자체가 실패해도 빈칸 대신 재시도 안내를 표시한다.

진행 중인 대화와 Goal을 보존하기 위해 서버를 재시작하지 않고 실행 중인 서버의 GPU 요청 처리만 교체했다. 저장된 서버 코드에도 같은 모듈을 연결해 다음 재시작 후에도 유지된다. 진단용 Node inspector는 반영 후 닫았다. 학습 프로세스와 데이터는 변경하지 않았다.

검증: 프런트엔드 빌드 성공, 기존 서버 테스트 9개 통과. 실제 서비스의 인증된 GPU API는 HTTP 200과 장치 7개(정상 6개, 오류 1개)를 반환했다. 로컬 Chromium 1440×900 화면에서 GPU 행 7개 및 GPU 3 오류 문구를 확인했으며, 왼쪽 아래 표시 영역 전체가 화면 안에 있었다. 외부 클라이언트 접속 검증은 수행하지 않았다.

화면 캡처: exp/261026/gpustat_interface/verified.png.

GPU 3번의 드라이버 오류 자체는 남아 있으며 이번 변경은 상태 표시 복구다.
