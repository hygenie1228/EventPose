# GPU3 장치 장애와 보존 체크포인트

반복 event-only 학습의 물리 GPU3(B1:00.0)에서 NVML Unknown Error가 확인됐다. 비어 있는 GPU4 UUID로 수행한 독립 CUDA 연산도 드라이버 초기화 실패로 종료했다. 저장된 last.pt를 CPU에서 실제 로딩해 step697·성공 update694·학습 경과5863.92초와 모든 학습 tensor 유한값을 확인했다. 주실험 6조건 및 반복 앞4조건의 전체 Test·원시 검증 완료 결과는 보존되어 있다. 남은 반복 2조건과 동일 GPU 속도·최종 감사는 미완료다. 하드웨어 복구 전에는 전체 Goal 완료를 선언하지 않는다. 원시 진단 증거는 `exp/261026/device34_body_28h/hardware_failure_2336.json`과 `logs/hardware_recovery_probe.log`다.

오류 로그에는 targets에서 index16/배치16 범위 오류가 보이지만 GPU 장치/드라이버 오류가 동시에 발생했다. 원인이 코드인지 장치 오류로 인한 손상인지 단정하지 않는다. GPU4 UUID의 CUDA probe도 초기화 실패했다. 실패 프로세스 PID35159의 등록 PID/PGID/시작tick/명령을 검증한 뒤 SIGTERM과 SIGKILL을 전송했다. 커널/드라이버에 남아 있는지 실제 /proc identity로 재확인해야 하며 생존 상태에서 중복 실행하지 않는다.

복구 시 configuration을 바꾸지 않고 원래 trial 종료시각과 전체 마감을 보존하는 resume을 우선 검토한다. 실패로 잃은 시간·실제 처리량을 숨기거나 새3시간을 중복 지급하지 않는다. GPU2 학습 PID35155 및 외부 작업은 조작하지 않았다.
