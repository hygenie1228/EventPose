# Viewer 탭 모두 닫기 버튼

Viewer 탭 줄 오른쪽에 항상 보이는 `모두 닫기` 버튼을 추가했다. 탭 목록은 별도로 가로 스크롤되며 버튼은 고정된다. 열린 탭이 없으면 버튼은 비활성화된다.

저장하지 않은 변경이 있는 경우 해당 탭 수를 표시하고 한 번 확인한다. 취소하면 편집 내용과 탭을 유지한다. 모두 닫으면 편집기를 정리하고 마지막 파일 복원 기록도 제거해 새로고침 시 다시 열리지 않도록 했다. 개별 탭으로 마지막 파일을 닫을 때도 같은 정리를 적용했다.

검증: 프런트엔드 빌드 성공. 실행 중인 서비스에 로컬 Chromium으로 접속해 여러 파일 탭 닫기, 버튼 표시 위치, 빈 상태 비활성화, 미저장 변경 확인의 취소·닫기, 새로고침 후 탭 복원 방지를 확인했다. 테스트는 파일을 저장하지 않았으며 실제 파일 내용은 변경하지 않았다. 서버 재시작은 필요하지 않았다.
