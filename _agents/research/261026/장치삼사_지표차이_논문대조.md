# MPJPE와 PA-MPJPE 차이 확인

사용자 질문: 두 지표가 약 두 배 차이 나야 하는가? 고정 배율 규칙은 없다. 현재 holdout의 MPJPE는 pelvis 평행이동만 제거한 관절 오차이고 PA는 추가로 회전·등방성 양의 scale·평행이동을 least-squares 적합한다. src/utils/humanpose_metrics.py joint_errors의 relative는 root 평행이동만 적용하며 PA와 계산 경로가 분리돼 있음을 코드에서 확인했다.

12:20경 RGB3 holdout: 비정렬 관절 오차 78.1421mm, pelvis 정렬 MPJPE 37.1305mm, PA-MPJPE 26.4662mm. 두 정렬 지표 비율 약1.40이다. 비정렬 수치와 pelvis 정렬 수치를 혼동하지 않는다. Test 결과가 아니며 벤치마크 직접 비교 근거가 아니다.

Multi-HMR 원논문 ECCV2024 Table5(a), 3DPW, ViT-L/14 896 조건은 MPJPE61.4mm·PA-MPJPE41.7mm(약1.47배)다. 원문 https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/03364.pdf 의 13페이지에서 확인했다. ETRI22관절·body holdout과 3DPW의 관절/데이터/학습·평가 조건이 다르므로 절대값 우열 비교를 하지 않는다. 학습·평가 규칙은 변경하지 않는다.
