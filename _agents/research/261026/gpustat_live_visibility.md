# GPUSTAT 실시간 표시 확인 및 보완

사용자가 인터페이스에서 실시간 GPUSTAT이 보이지 않는다고 제보했다. 로컬 인증 API는 HTTP 200으로 정상 응답했으며, 수정 전 데스크톱 Chromium에서도 5초 간격 요청 3회와 GPU 7개 행을 확인했다. 현재 코드 기준으로 갱신 중단은 재현되지 않았다. 다만 갱신 시각이 없고 767px 이하 화면은 탐색기 전체를 숨기므로 모바일에서는 GPUSTAT을 볼 수 없었다. 사용자 브라우저의 정확한 원인은 확정하지 않았다.

GPUSTAT에 마지막 성공 조회 시각, 5초 갱신 안내, 수동 새로고침 버튼을 추가했다. Chat 패널 제목줄의 GPU 버튼은 상태 팝업을 열며 모바일에서도 사용할 수 있다. 기존 상태 영역을 팝업으로 이동하고 닫으면 원래 위치로 복원하여 중복 조회를 만들지 않는다. 중복 요청 방지와 15초 요청 제한을 추가했다. 실패 시 기존 GPU 값을 유지하면서 연결 지연을 알리고 다음 주기에 재시도한다. 화면 자산 버전은 gpu-live-23으로 변경하고 빌드했다. 서버 재시작이나 학습 작업 변경은 수행하지 않았다.

검증: 실제 로컬 서비스 대상으로 Playwright 1440×900 및 390×844 각각 GPU 7개 표시, 자동 갱신, 화면 내 배치, 팝업 닫기/재열기, 모의 HTTP 503 뒤 복구, 브라우저 예외 없음 확인. 각 화면에서 정상 응답 4회를 관찰했다. npm 빌드와 기존 서버 테스트 9개도 통과했다. 회귀 검증 코드는 src/apps/research-workbench/test/gpu-live.mjs에 저장했다. 외부 사용자 단말 접속은 검증하지 않았다.

GPU 3번 드라이버 조회 오류는 현재도 표시되며 하드웨어나 드라이버를 재시작하지 않았다. dataset/ 및 data/에 쓰지 않았다.

## 사용자 요청 반영: 갱신 안내 제거

정상 조회 시 실시간·갱신 간격·조회 시각 문구와 해당 행을 제거했다. 자동 갱신은 유지하며 오류 때만 연결 지연 안내를 표시한다. 자산 버전은 gpu-live-24다.
