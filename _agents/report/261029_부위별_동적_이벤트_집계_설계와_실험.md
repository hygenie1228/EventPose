RGB ViT의 공간 token에서 torso·좌우 팔·좌우 다리·머리의 여섯 query가 부위 표현을 읽는다. 이벤트는 현재 RGB3의 실제 시각 이전 0–33·33–100·100–200ms의 겹치지 않는 세 구간으로 나누고, 공유 patch embedding과 공간 Transformer로 표현한다. 각 RGB ray에서 보정된 여러 깊이 후보를 사용해 event 좌표를 찾는다. 같은 device여도 두 센서의 픽셀은 직접 일치하지 않는다.

부위별 RGB 표현과 시간별 이벤트 표현으로 집계 가중치를 예측한다. 현재 위치를 잘 설명하는 과거를 선택하고, 유효한 이벤트가 없으면 null을 선택한다. 부위별 시간 가중치를 RGB 공간 token에 전달해 원래 RGB 표현에 residual로 더한다. 출력층은 0으로 초기화해 시작 시 RGB 예측을 보존한다. 기존 Multi-HMR pose head가 SMPL-X를 복원하고 동일 regressor로 관절을 얻는다. 신뢰도 확률을 추정한다는 주장은 하지 않는다.

학습 때만 관절 주변의 약한 공간 분포로 부위 query를 지도한다. 추론에는 RGB·이벤트·카메라 보정만 입력하며 GT pose, GT part box, GT motion을 넣지 않는다. 학습손실은 3D 자세·검출·회전·shape·root 및 약한 부위 분포 지도다.

## 공정한 비교와 개선 원칙

모든 새 조건은 기존 Train holdout으로 선택된 동일 RGB3 checkpoint에서 시작한다. 이 공통 사전단계는 기존 RGB 학습 1,651업데이트이며 새 실험을 원본 미세조정 전 결과로 부르지 않는다. 새 학습은 같은 seed·split·batch·backbone/head 학습률·최대 3,000 성공 업데이트·3시간 상한을 사용한다. 고정 집계와 두 동적 집계는 동일한 세 시간 구간과 같은 여섯 query 구조를 사용한다. 전신 동적 집계는 부위 가중치를 평균해 모든 부위에 같은 시간 가중치를 적용하므로 부위별 선택 효과를 분리한다. RGB 단독은 이벤트 픽셀을 읽지 않는다.

검증 오차로만 수정과 checkpoint를 선택한다. Test는 frozen checkpoint의 최종 비교용이며 Test로 방법을 고르지 않는다. 실제 이벤트 gradient, 부위별 가중치 변화, zero/missing/shuffled-event 개입을 검사한다. 합성 blur는 이번 원본 데이터 성능 개선을 대신하지 않는다.

## 데이터 시각과 한계

기존 GT와 Test는 공통 시각을 사용하고 RGB3는 해당 시각 이전의 최신 프레임이다. 이번 이벤트 구간 끝은 더 엄격하게 실제 RGB3 timestamp로 제한한다. 19:13 KST에 실제 고정 질의의 시각을 전수 확인한 RGB–GT 최대 지연은 Train 44.592ms·Train 내부 검증 33.900ms·Test 44.305ms다. 앞서 기재한 최대 약33ms는 전체 범위를 대표하지 않아 정정했다. 지연 조건은 모든 방법에서 같다. 저장된 이벤트는 CSR 활성 픽셀 관측이며 원시 이벤트의 개별 발생 횟수를 복원한 것이 아니다.

78세션의 캐시30,896질의에서 세 구간의 경계·가장 이른/늦은 관측 시각을 검사해 RGB 이후 이벤트가 포함되지 않았음을 확인했다. 이 인과성 확인은 원본 캐시와 원본 입력에 대한 것이다. Batch 순환 셔플은 이벤트와 RGB의 대응을 일부러 깨는 진단 개입이므로 각 수신 질의의 인과적 시각 정렬을 유지하는 새 방법으로 해석하지 않는다. 실제 실험 계획 질의는 Train6,501·검증288·Test24,080이며 캐시 전체 행 수와 구분한다. 운동 감독의 표본 연결·무효 마스크·Train 전용 optimizer 허용·추론 입력 금지도 확인했다. 원본78개 이벤트 archive의 크기·수정시각이 생성 당시 기록과 같았으나, 이것을 전체 원본 바이트 해시 일치로 과장하지 않는다. ## 장면 단위 부위 표현의 한계

현재 여섯 query는 **프레임 전체에 공유되는 의미적 부위 query**다. 사람마다 별도로 여섯 query를 만드는 구조는 아니다. 학습용 부위 지도도 같은 부위에 속하는 관절의 주변 분포를 사람 간 합쳐 사용한다. 따라서 단일 주인체 장면의 부위별 시간 집계를 검증하는 설계이며, 여러 사람이 서로 다르게 움직일 때 사람별로 다른 시간 범위를 선택한다고 주장하지 않는다. Instance-aware 확장은 별도 구조 변경과 검증이 필요하다.

## 검증에 따른 별도 V2 설계

V1의 Train 내부 검증과 학습 기록에서 동적 이벤트 선택 확률이 약 10⁻⁵까지 작아지는 징후를 확인했다. 또한 시간 가중합 뒤의 `Linear`에 bias가 있으면 null을 선택해도 학습된 bias가 RGB 표현을 바꿀 수 있다는 구조 반례가 발견됐다. 이는 실제 학습된 bias 수치를 측정한 결과와 구분한다. **따라서 V1의 작은 정확도 개선만으로 이벤트 정보의 효과를 주장하지 않는다.** V1 학습과 원래 네 조건의 평가는 그대로 유지한다.

후속 V2는 별도 소스와 해시로 동결했다. (1) projection bias를 제거해 all-null message가 정확한 0 residual이 되게 한다. (2) 상대적인 부위 배정뿐 아니라 학습된 부위 지도 density로 공간 support를 만들고 약한 위치의 residual을 억제한다. 이것은 GT 인체 segmentation이 아니다. (3) 처음 500개 성공 업데이트에서만 균등 시간 집계로 이벤트 표현을 학습하고 이후 null을 포함한 학습형 집계를 사용한다. 추론에서는 warmup을 항상 끄므로 checkpoint를 step0 상태로 재로드해도 learned gate를 평가한다.

V2 RGB·고정·전신 동적·부위 동적 네 조건은 같은 초기 RGB와 학습 예산을 사용한다. Global/part는 같은 support·warmup·초기 null bias −2·gate 학습률 10⁻⁴를 사용한다. 마지막 null 선택을 금지하지 않는다. Global/part 각각 no-support와 no-warmup 대조를 추가해 공간 억제·학습 과정·부위별 시간 선택을 구분한다. 모든 최선 checkpoint는 warmup 이후의 검증 결과로 선택한다.

V2는 모드 전환·state reload·all-null identity·보정 유효 patch·실제 gradient·v1 분기 보존 등 CPU 17항목을 통과했다. 기존 모델의 frozen Train-holdout 개입 진단이 완료된 뒤 새 8-step 실데이터 pilot부터 실행한다. 이 설계 선택에 새 Test 결과를 사용하지 않았으며, **V2의 성능 개선은 아직 입증되지 않았다.**

## 검증에 따른 V3: 부위별 움직임으로 집계 길이 결정

V2는 이벤트 선택 확률을 회복했지만, Train 내부 holdout의 frame PA-MPJPE는 RGB 24.7531mm보다 높은 24.7795mm였다. 이벤트를 제거한 경우는 24.7472mm로 오히려 낮았다. 따라서 이벤트 사용량 증가를 성능 개선으로 해석하지 않는다. 선택된 이벤트 안에서 세 시간 구간의 조건부 가중치 최댓값−최솟값 중앙값도 0.0113에 불과해, 부위마다 집계 시간을 충분히 달리 선택했다고 보기 어렵다. 이 판단과 V3 설계에는 Test를 사용하지 않았다.

V3는 **이벤트에서 추정한 부위별 최근 움직임 → 집계 길이 → 부위별 RGB 보완**을 명시적으로 연결한다. 세 과거 구간의 부위 이벤트 특징, 구간 사이 특징 변화, 부위 임베딩, 보정된 국소 이벤트 점유량을 작은 motion head에 넣어 최근200ms의 영상면 경로 길이와 signed UV 변위를 추정한다. 경로 추정치가 커지면 짧은 창을, 작아지면 긴 창을 사용한다. 예를 들어 6px의 허용 이동량을 기준으로 200ms 경로가30px이면 약40ms, 6px이면 약197ms가 된다. 이는 원리를 설명하는 계산 예이며 실제 학습 결과가 아니다.

집계 길이는 `τ=clip(200·r/(예측 경로+0.1), 33, 200)`ms이며, 부위별 학습 가능한 `r`은6px에서 출발한다. 세 구간 중심16.5/66.5/150ms에 대해 `sigmoid((τ−구간 중심)/10)`을 정규화해 조건부 시간 가중치를 만든다. 별도의 event-use gate가 전체 이벤트 사용량과 null 선택을 결정한다. **시간 선택과 이벤트 사용 여부를 분리**하므로, 관측이 부족한 부위에 오래된 이벤트를 반드시 쓰도록 강제하지 않는다. 이 집계 길이는 세 구간 특징을 부드럽게 가중하는 파라미터이며, 원시 이벤트를 정확히 그 시각에서 잘라 다시 인코딩하는 방법은 아니다.

학습 때만 GT에서 얻은 과거200ms 경로·UV로 motion head를 보조 감독한다. Train6501 query 중 유효6491 query와 각 부위의 유효 마스크만 손실에 포함하며, 무효10 query는 경로·UV 손실과 gradient의 분모에서도 제외한다. 추론에는 RGB, 과거 이벤트, 카메라 보정만 들어가며 GT motion·part·pose를 입력하지 않는다. RGB-only 대조군도 같은 보조학습을 받되 RGB 부위 특징만 사용하고 이벤트 픽셀을 읽지 않는다. 또한 보조학습이 없는 강한 V2 RGB 대조군을 항상 함께 비교하여, RGB 보조학습의 열화로 생긴 겉보기 이득을 배제한다.

네 주조건은 RGB-only, 고정3구간 균등집계, 전신 공통 동적집계, 부위별 동적집계다. 후속 대조는 같은 motion head·보조손실을 유지하면서 query별 창을 부위별 고정 prior로 바꾸는 static control, global/part 각각의 motion 보조손실 제거, 최근33ms 고정집계를 포함한다. V1/V2 forward는 변경하지 않고 V3를 별도 소스·해시로 동결했다. CPU18검사를 통과했으며, 실제 CUDA pilot·본학습·전체Test 통과 여부는 자동 실행 기록과 결과표에서 별도로 확인한다. 아직 V3의 정확도 개선이나 동적 집계 성공을 주장하지 않는다.

진단 출력에는 query별 예측 경로, UV, 집계 길이, 이벤트 선택 확률, 시간/null 가중치를 함께 저장한다. 실제 두 고정 사례와 전체 holdout에서 같은 부위의 frame별 움직임 변화에 창이 반응하는지, 느린 다리와 빠른 팔을 실제로 구분하는지 검증한다. GT 관계 분석은 세션별 군집을 보존하며, 부위×frame을 독립 사람 수로 세지 않는다.

## V3의 실제 시간 선택과 자세 정확도의 분리

![실제 V3 모델의 부위별 시간 선택과 운동 진단](/home/namhj/EventPose/exp/261029/part_aware_dynamic_aggregation/figures/v3_part_dynamic_motion_relation.png)

![기존과 같은 두 장면의 실제 V3 부위 지도와 시간 가중치](/home/namhj/EventPose/exp/261029/part_aware_dynamic_aggregation/figures/v3_part_dynamic_actual_examples.png)

Train 내부 검증288프레임·9피험자의 실제 frozen V3 부위 모델에서, 부위별 예측 시간창의 질의 간 표준편차는 약45.2~60.2ms였다. 빠른 팔의 조건부 구간 중심 이력은 평균 약31.6~32.2ms, 다리는59.4~59.7ms였다. 피험자 안에서 반복된 frame/part cell의 GT 운동과 조건부 이력 사이 기술적 Spearman의 중앙값은 −0.832였다. 독립 표본을1,728명으로 취급하거나 유의성 검정으로 해석하지 않는다. 예측 운동과 시간창 자체의 관계는 설계식으로 정해지므로 그 둘의 상관은 별도의 성공 증거가 아니다.
