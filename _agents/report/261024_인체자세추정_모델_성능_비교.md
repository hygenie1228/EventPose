# NLF / Multi-HMR Test 비교

Test 64세션·device0, 10초 × 5개 고정 구간으로 총 320구간·96,124 RGB 프레임을 평가했다. 아래 신체 22관절 지표는 모든 모델에 공통 매칭된 104,863 사람-프레임을 사용한다. 오차 단위는 mm이며 낮을수록 좋다. 미검출은 0 오차로 처리하지 않고 검출률로 따로 보고한다.

| 모델 | 첫 프레임 정렬 MPJPE | 첫 프레임 정렬 PA-MPJPE | 프레임별 정렬 MPJPE | 프레임별 정렬 PA-MPJPE |
|---|---:|---:|---:|---:|
| Multi-HMR 기본 모델 | 160.04 | 146.65 | 94.94 | 58.19 |
| NLF 기본 모델 | 116.61 | 111.94 | 78.83 | 53.31 |
| Multi-HMR 학습 모델 | **68.53** | **73.26** | **46.68** | **32.54** |

각 구간의 정확한 첫 프레임에서 모든 모델에 공통 검출된 사람만 포함했다. 첫 프레임 정렬은 그 변환을 10초 전체에 고정하고, 프레임별 정렬은 매 프레임 다시 계산한다. MPJPE 정렬은 pelvis 평행이동만 사용하며, PA는 반사를 허용하지 않는 회전·양의 등방 스케일·평행이동을 사용한다. PA는 스케일 오차를 제거하므로 metric scale의 절대 위치 정확도는 아래 정렬 전 오차로 판단해야 한다.

## 절대 위치·검출률·관측 처리 속도

| 모델 | 정렬 전 MPJPE (mm) | Pelvis 위치 오차 (mm) | GT 매칭률 (coverage) | 관측 fps |
|---|---:|---:|---:|---:|
| Multi-HMR 기본 모델 | 272.30 | 252.69 | 97.941% | **7.21** |
| NLF 기본 모델 | 127.63 | 101.80 | 98.691% | 5.12 |
| Multi-HMR 학습 모델 | **70.58** | **52.81** | **98.723%** | 4.97 |

관측 fps는 영상 디코딩·모델 실행·관절 복원·GT 매칭을 포함하지만 최초 모델 로딩과 영상의 SSD 복사는 제외한다. 다른 GPU 작업과 동시에 측정됐으므로 이 값만으로 공정한 속도 배수를 단정하지 않는다.
