# NLF 최종 평가 재개 안내

2026-10-24 13:56 UTC 확인 기준이다. NLF 세 trial 학습은 고정 종료 시각 이후 모두 완료됐다. 내부 검증으로 `last_two_stages`의 step 53,989 체크포인트가 선택됐으며, Test를 선택에 사용하지 않았다. 내보낸 모델은 전체 1,806개 tensor 검사를 통과했다.

자동 최종 Test는 여섯 worker 모두 `humanpose_metrics` import 경로 오류로 중단됐다. `src/utils/pose_evaluation.py`의 import를 수정했고, 지표 자체 검사와 실제 `Collector.collect`의 사람 매칭 회귀 검사를 통과했다. 학습·관리 프로세스는 재시작하지 않았다.

현재 웹 에이전트 실행 환경은 GPU 장치가 노출되지 않아 CUDA 장치가 0개다. 아래 작업은 GPU가 보이는 호스트 터미널에서 수행해야 한다. 데이터·GT·Test 구간을 변경하지 않는다.

먼저 기존 평가가 실행 중이지 않은지 확인한다. 실행 중이면 아래 평가 명령을 중복 실행하지 않는다.

```bash
pgrep -af 'scripts/evaluate_nlf.py|src/utils/runtime_benchmark.py'
```

기존 평가가 종료된 것이 확인되면, 저장된 학습 결과로 평가만 이어 실행한다. 완료된 구간이 있으면 평가 코드가 건너뛴다. 이 명령은 학습이나 학습 관리 프로세스를 시작하지 않는다.

```bash
cd /home/namhj/EventPose
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=2 \
LD_LIBRARY_PATH=/home/namhj/miniconda3/envs/videohor/lib/python3.10/site-packages/nvidia/cudnn/lib \
.venv-humanpose/bin/python scripts/evaluate_nlf.py supervise \
  --method nlf_finetuned \
  --checkpoint exp/261024/nlf_finetune_12h/checkpoints/best_full.torchscript \
  --gpus 3,4,5,6 --workers 4 --batch 16
```

이 실행은 사용자 최신 지정에 따라 GPU 3–6으로 전체 320구간 Test를 평가하고, 네 모델 공통 표본으로 재집계한 다음, GPU 3에서 네 모델을 순차 측정하고 최종 보고서를 다시 생성한다. GPU 0–2는 사용하지 않는다. 장시간 실행 상태 확인은 30분 간격을 유지한다. 평가와 결과 검증이 끝나면 Goal을 종료한다.

전체 평가와 속도 측정이 종료된 뒤 다음 검증을 수행한다. 구문 검사만으로 최종 통과를 주장하지 않는다.

```bash
PYTHONDONTWRITEBYTECODE=1 .venv-humanpose/bin/python tools/audit_nlf_comparison.py
```

최종 산출물은 `exp/261024/nlf_finetune_12h/comparison.json`, `runtime_benchmark/summary.json`, `final_audit.json` 및 `_agents/report/261024_인체자세추정_모델_성능_비교.md`다. 아직 최종 Test·속도 측정·종합 추천 검증이 끝나지 않았으므로 목표는 미완료다.
