## 좌표와 입력 검증

device3·4의 RGB와 이벤트는 센서별 내외부 calibration으로 분리 처리했다. 주 센서는 원본 Multi-HMR backbone/검출기를 사용하고 보조 센서는 별도 encoder와 보정된 ray·camera origin의 attention으로 결합했다. 이 구현은 주·보조 센서가 비대칭이다. 보조 RGB도 사전학습된 두 번째 Multi-HMR 대신 작은 CNN을 사용하므로 두 개의 대형 RGB backbone을 사용하는 방식 전체의 성능을 대표하지 않는다. 보조 encoder가 추가되는 조건의 parameter·비용은 최종 속도 검증에서 구분한다. 보정 timestamp 기준 과거 RGB 프레임 및 count33 극성분리 이벤트를 대응시켰으며 미래 이벤트, event MP4, GT box/pose/depth를 추론 입력으로 사용하지 않았다. 이벤트 두 센서 조건은 실제 픽셀 접근 기록에서도 RGB 입력이 없어야 통과한다. 검출 대응은 각 주센서의 원래 픽셀 평면에서 동일 GT 인물에 대해 계산하고, 대응된 3차원 예측은 공통 device3 RGB 카메라 좌표에서 원형 그대로 평가했다. 다른 카메라로의 재투영 때문에 깊이 오차가 검출 실패로 중복 집계되는 것을 방지했다.
