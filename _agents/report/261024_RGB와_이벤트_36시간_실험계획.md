# RGB와 이벤트 36시간 실험 목표

36시간 이내에 device0의 RGB·event 기반 3D human motion 실험을 완료·검증하고, event가 정확도와 속도의 균형을 유의미하게 개선하는지 한글 보고서로 결론낸다. 현재 NLF 최종 Test PID46605와 이후 동일 GPU 속도 비교를 중복 실행 없이 이어받아 기존 Multi-HMR 기본/학습 및 NLF 기본/학습 4모델 비교를 먼저 마친다. _agents/research/261024/nlf_goal_handoff.md와 최신 인계·실행 기록을 읽는다. NLF 학습은 이미 고정 시각 2026-10-24 13:47:05 UTC에 종료됐으므로 재학습/관리 재시작하지 않는다. 기존 12시간 작업창을 재설정하지 않는다.

새 확장 목표의 고정 시작은 2026-10-24 17:17:17 UTC, 마감은 2026-10-26 05:17:17 UTC(36시간)다. 기존 평가 잔여시간·구현·캐시·학습·평가·보고서 시간을 전부 포함하며 재접속/재개 때 연장하지 않는다. 사용자 승인에 따라 독립 타이머가 마감에 이 Goal을 paused로 바꾸고, 이 목표에 등록한 미완료 작업만 체크포인트/로그를 보존하며 정지시킨다. 다른 agent/사용자 작업에는 손대지 않는다. 모든 요구를 실제 검증해 조기 달성하면 complete로 종료하고, 마감 미달성은 완료로 속이지 말고 paused 및 남은 절차를 기록한다.

1. 기존 4모델의 동일 실제 Test 320구간·96,124 RGB프레임과 동일 GPU 전체 파이프라인 속도 결과를 검증한다. 정확도·절대 위치·검출률·시간적 일관성·속도에서 장단점을 확인하고, 학습 내부 holdout 및 속도/메모리 근거를 함께 사용해 주 알고리즘 하나를 선택·고정한다. 임의 가중합으로 우승을 만들지 않는다. 이미 완료된 데이터·체크포인트·결과를 보존한다.
2. 다른 agent가 갱신하는 _agents/report/261025_이벤트데이터분석.md를 중요 단계마다 읽고 채택 버전/근거를 스냅샷으로 기록한다. 해당 agent 작업을 수정·재시작하지 않는다. dataset/의 device0만 사용하고 dataset/, orig_dataset/, etri_processed/, data/는 읽기 전용이다. Train219세션68명/Test64세션20명 분리와 Train 내부187학습/32holdout을 유지한다. Test로 인코딩·하이퍼파라미터·체크포인트를 선택하지 않는다.
3. 보정된 RGB/event 타임스탬프, 가용 구간/누락, 극성·저장 해상도·GT 좌표계·센서 내외부 파라미터를 검증한다. event.npz는 저장된 희소 이벤트 프레임이므로 원시 이벤트 수/세부 시각을 복원했다고 주장하지 않는다. event와 RGB의 서로 다른 시점/좌표를 동일 픽셀로 가정하지 않는다. 검증된 보정 또는 센서별 encoder와 기하를 고려한 fusion을 사용하며, RGB/event-only 조건에 허용되지 않은 GT box·pose·깊이 입력이나 미래 event를 사용하지 않는다. GT는 supervision과 평가에만 사용한다.
4. 선택 알고리즘에서 네 입력 조건을 공정하게 비교한다: (a) 미세조정 없는 원본 RGB checkpoint, (b) RGB-only 단순 미세조정 baseline, (c) event-only, (d) RGB+event. event-only는 학습·추론·검출/추적/crop 결정 모두 RGB를 사용하지 않는다. 각 조건의 train/test 입력 시나리오가 같아야 한다. event-only와 RGB+event 각각 네 인코딩을 독립 학습·평가하여 기본 비교행은 총10개다. 인코딩 초기 후보는 A:33ms 양·음 극성 분리 누적2채널, B:100ms를3시간구간×2극성으로 분리6채널, C:극성별 시간표면2채널(감쇠20ms, 최대과거200ms), D:tools/visualize_data.py의 회색조 프레임 표현(배경128·양극성255·음극성0)이다. D는 보정 timestamp가 RGB시각 이하인 최근 저장 event프레임을 수치 입력으로 재현하며 MP4손실압축이나 도구의 frame_idx×50 동기화 가정은 사용하지 않는다. 분석 보고서와 Train holdout 파일럿에 근거해 본학습 전에 정확히4종을 확정·동결하고 메타데이터를 보존한다. 단순 표시용 컬러 영상 대신 수치 채널을 encoder 교체/입력 adapter로 전달하고 희소 신호 보존 축소·정규화·극성 상쇄 방지를 검증한다.
5. event 전처리가 병목이면 exp/YYMMDD/{실험}/에 설정·소스 지문·프레임 매핑이 있는 캐시를 먼저 생성하고 검증한다. GPU2–6만 사용하며 기존 GPU3–6 평가를 방해하거나 중복 실행하지 않는다. 과학 계산은 .venv-humanpose/bin/python으로 한다. 이전의 안정적 fine-tuning(사전학습 초기화, head/adapter 우선→필요 시 후반 backbone, 작은 학습률, AMP/유한 gradient 검사, 주기적 체크포인트, Train holdout 선택)을 계승한다. 통제 비교군의 초기화·데이터·증강·batch·학습량/예산을 맞추고 각 주 trial은 약12시간의 반나절 학습을 목표로 GPU5개 안에서 병렬/순차 배치한다. 총36시간 마감에서 역산해 모든10조건의 최종 Test/속도/검증 시간을 남긴다. 기존 RGB 학습 결과 재사용은 조건 일치와 총 학습량을 입증할 때만 허용하고 다르면 통제 baseline을 학습한다. 예산 안에서 최종 baseline/fusion 반복 seed도 우선 확보하고 미실시/짧은학습은 명시한다.
6. 같은 device0 Test 구간과 GT/프레임 대응을 사용해 첫 frame0 고정 정렬 및 프레임별 MPJPE/PA-MPJPE(mm), 정렬 전 절대 MPJPE·pelvis 위치, 검출률, 속도·가속도 오차를 집계한다. 전체 GT 분모의 검출률과 모든 모델 공통 표본의 자세 오차를 함께 보고하고 결측을0오차로 처리하지 않는다. 동일 GPU2–6 중 하나에서 인코딩/캐시 I/O·디코드·검출·모델·인체복원·매칭·저장을 포함한 실제 전체 속도와 모델 로딩·메모리를 비교한다. 온라인 인코딩 비용과 사전 캐시 속도를 분리하고 cache 생성시간/용량도 보고한다.
7. RGB+event 각 인코딩을 RGB-only baseline과 paired 비교하고 세션/피험자 단위 cluster bootstrap95% 신뢰구간 및 다중비교 보정을 사용해 효과크기·실용적 이득·속도비용을 평가한다. 프레임을 독립 표본으로 과대계산하지 않는다. 가능한 반복 seed와 빠른동작/느린동작/정지 구간 분석으로 재현성을 확인하며, 단일seed/부족한통계근거는 명시하고 개선이 없으면 그대로 결론낸다.
