# RGB·이벤트 현재 실험 시도와 시각화

**새 RGB/event 학습 모델의 전체 Test 평가는 아직 실시하지 않았다. 이 문서는 학습 진행·입력 시각화 기록이며 최종 성능 보고서가 아니다.** 사용자가새split실험을새AI Agent로이관하도록지시해이전실험은중단·checkpoint보존정리를요청했다. 아래는이전split의진행기록이며새split결과로재사용하지않는다.

Root absolute depth error(RPE-Z)는비정렬카메라좌표의pelvis깊이 `mean(|Z_pred − Z_GT|)`이며단위mm다. 3D RPE와구분하며,다른네지표와동일공통Test표본에서계산한다. 현재새학습모델은Test미평가이므로수치를대신채우지않았다.


내부 holdout은 Train219세션 중 별도로 둔32세션으로, checkpoint 선택에 사용한다. PA는3D pose의회전·이동·크기를맞춘후의오차이며, **비정렬 절대위치 Test오차가아니다.** 중간수치로최종성능이나이벤트효과를판정하지않는다.


**네 지표의 정의:**

- **first frame-aligned MPJPE**: 정확한 구간 frame0에서 pelvis 평행이동을 구해10초 전체에 고정한다.
- **first frame-aligned PA-MPJPE**: frame0에서 proper Sim(3)의 회전·이동·scale을 구해10초 전체에 고정한다.
- **frame-aligned MPJPE**: 매 프레임 pelvis 평행이동을 다시 구한다.
- **frame-aligned PA-MPJPE**: 매 프레임 proper Sim(3) 정렬을 다시 구한다.

모두 신체22관절·mm다. 이는 RGB/event 픽셀 정렬 여부와 다른, **평가용3D정렬 정의**다. 정렬 전 절대MPJPE·pelvis위치·검출률·시간적오차는 별도 보조표에 둔다. 내부holdout은 무작위로 샘플링한 프레임이므로10초시퀀스의first frame-aligned지표를 대신 채울 수 없다. 위 네 열은 전체Test에서 실제 계산할 때만 수치를 넣는다.


## 픽셀 비정렬 입력 시각화

![같은 보정 시각의 RGB와 네 이벤트 인코딩](/home/namhj/EventPose/exp/261024/rgb_event_36h/progress_visuals/input_encodings.jpg)

동일한 내부 holdout 세션에서 첫·중간·마지막 고정 표본을 사용했다. 첫 열은RGB와GT(초록), 나머지는 각기 다른 시점의 event 센서 좌표에 남겨둔 수치 입력 표시다. RGB/event를같은픽셀로겹치지않았고GT깊이워핑을사용하지않았다. count33·surface20의양극성은빨강/음극성은파랑, bins100은3시간구간을각각표시했다. 이는표시용색이며학습은분리수치채널을쓴다.

## 모델 선정의 과거 근거

이전 Multi-HMR/NLF4모델 비교는 [기존 모델 비교 보고서](261024_인체자세추정_모델_성능_비교.md)에 보존한다. 현재의10조건은 **모두 Multi-HMR 기반**이다. 새학습모델의Test예측이생기기전에는과거NLF그림을현재결과로제시하지않는다.

## 남은 검증

RGB/fusion5개 학습완료, event-only4종 본학습, 모든10조건 전체Test, 같은GPU의온라인/캐시속도18회, 대응cluster통계와보고서숫자감사가남아있다. 현재추천은기존완료결과에근거한Multi-HMR계열이며, 이벤트추가의최종효과와최종모델하나는새전체Test후확정한다.

시각화근거와선택프레임: `exp/261024/rgb_event_36h/progress_visuals/receipt.json`. 원본데이터읽기전용·GPU미사용CPU렌더링으로기존학습을중단하지않았다.



## 현재 실행 순서

정상GPU는2·4·5·6이며현재RGB/fusion4개가학습중이다. 사용자지적에따라다음빈GPU부터event-only4종을우선배치한다. event-only는기능파일럿만완료했고본학습·Test는아직시작전이다. 진행중학습은중단하거나중복실행하지않는다.

## 새 split 실험 인계

새AI Agent의각fine-tuning trial은최대3~4시간,전체목표는24시간으로제한한다. 이전코드는경과시간으로중단하고중간epoch에서도checkpoint를저장하는방식이었다. 전체Train프레임을1회완주했다고보장하지않는다. 실제이전이벤트확장실험config의학습예산은12시간이었으므로이를3~4시간실험이었다고표기하지않는다. 새Agent는시간내처리량에맞는피험자/세션균형subset을사전에고정하고본샘플수·고유프레임수·epoch진행률·전체Train coverage를보고하도록지시했다.
