# 학습과 추론 속도 최종 비교

**기존 RGB 4개 모델의 전체 Test와 동일 GPU 순차 속도 측정이 완료된 결과로 갱신했다.** 이 파일명에 남아 있는 중간 표기는 기존 링크 유지를 위한 것이다. RGB/event 확장 실험의 결과는 아직 포함하지 않는다.

실제 Test 64세션·320구간·96,124 RGB 프레임이다. 자세 오차는 네 모델 공통 103,188 사람-프레임, 검출률은 전체 유효 GT를 분모로 사용한다. 오차 단위는 mm이고 낮을수록 좋으며 검출률과 fps는 높을수록 좋다.

## 정확도와 동일 GPU 전체 처리 속도

| 모델 | 프레임별 PA-MPJPE (mm) | 절대 MPJPE (mm) | GT 매칭률 (coverage) | 전체 처리 fps |
|---|---:|---:|---:|---:|
| Multi-HMR 기본 모델 | 58.28 | 273.77 | 97.941% | **7.369** |
| NLF 기본 모델 | 53.41 | 127.75 | 98.691% | 3.845 |
| Multi-HMR 학습 모델 | **32.63** | **70.85** | **98.723%** | 7.347 |
| NLF 학습 모델 | 62.20 | 152.64 | 97.733% | 3.836 |

측정 GPU: `3, GPU-898e54a8-dbfc-1296-b0b6-079dc8755d13, Quadro RTX 8000, 545.29.06`. 동일한 100프레임 구간 3개를 각 모델이 순차 처리했다. 영상 복사·디코드·전처리·검출·인체 복원·GT 매칭·결과 저장을 포함하며, 모델 로딩은 아래 별도 시간으로 분리했다. 이전 동시 작업에서 관측한 7.21/5.12/4.97 fps는 이번 공정한 순차 측정값으로 교체했다. 짧은 측정이므로 초기 실행 및 캐시 영향은 남는다.

## 추천과 한계

**우선 추천은 Multi-HMR 학습 모델이다.** 자세·절대 위치·검출률이 가장 좋고, 기본 Multi-HMR과 거의 같은 전체 처리 속도를 유지했다. NLF 학습 모델은 이번 Test에서 기본 NLF보다도 자세 오차가 커졌으므로 학습 내부 검증 개선을 Test 개선으로 해석하지 않는다. 시간적 가속도 오차는 기본 Multi-HMR이 더 낮은 항목이 있어 모든 지표에서 우세한 것은 아니다.

첫 frame0 고정 정렬/프레임별 정렬의 네 지표와 움직임 일관성은 [전체 모델 비교 보고서](/home/namhj/EventPose/_agents/report/261024_인체자세추정_모델_성능_비교.md)에 함께 정리했다.

원시 결과: `exp/261024/nlf_finetune_12h/comparison.json`, `runtime_benchmark/summary.json`. 전체1280개 결과 재집계 및 보고서 숫자 검증 기록: `final_audit.json`. Train 내부 검증을 체크포인트 선택에 사용했으며 Test를 사용하지 않았다. 학습 범위와 체크포인트 출처는 전체 비교 보고서와 각 실험 selected.json을 따른다.
