# 학습형 이벤트 집계: 논문 형식 구조도와 실제 데이터 예시

그림 개편: 2026-10-29 한국시간. [사용자가 공유한 참고 이미지](https://drive.google.com/file/d/1n8DTleXd0a1IjOEKSz4z5IL013sQB62-/view?usp=sharing)의 네 단계 배치·색상 구획·토큰 표현을 참고했다. **그림의 모든 문구는 영어로 작성했고, 입력 예시는 현재 데이터셋에서 가져왔다.** 네트워크는 제안 단계이며 새로운 학습·정확도 평가 결과가 아니다.

## 1. 핵심 그림

![실제 데이터 입력을 사용하는 네 단계 학습형 이벤트 집계 구조도](/home/namhj/EventPose/exp/261029/dynamic_aggregation_paper_figure/paper_pipeline_reference_style.png)

**핵심 아이디어:** RGB 질의 시각 이전의 이벤트에서, 부위마다 현재 자세를 설명하는 관측에 큰 가중치를 주고 불필요한 관측은 억제한다. 작은 모션에서는 유효한 긴 과거를 활용하고, 큰 모션에서는 서로 다른 과거 위치가 섞이지 않도록 최근 관측에 집중한다. 오래된 점이나 noise를 무조건 보존하지 않는다.

참고 이미지의 모션 추정·고정 gate 부분은 현재 아이디어에 맞춰 **신뢰도 학습과 가중 cross-attention**으로 바꿨다. RGB·이벤트·출력 형식 설명용 인체는 데이터셋의 실제 자료다. 토큰 사각형과 가중치 행렬은 구조 설명을 위한 도식이며 측정된 attention이 아니다. 마지막 인체는 **원본 SMPL-X GT로 직접 렌더링한 참조**로, 제안 모델의 예측 결과가 아니다.

## 2. 실제 관측이 보여주는 집계의 필요성

![실제 팔·다리·약한 관측의 짧은 누적과 긴 누적 비교](/home/namhj/EventPose/exp/261029/dynamic_aggregation_paper_figure/actual_evidence_insets.png)

**팔:** 긴 창에서 서로 다른 과거 위치가 넓게 섞인다. **다리:** 짧은 창에서 드문 관측이 긴 창에서 더 나타난다. **약한 관측:** 점이 늘어도 인체 구조가 그만큼 명확해지지는 않는다.

이것이 단순히 같은 시간이나 같은 개수를 모으는 것에서 더 나아가, **무엇을 얼마나 사용할지 학습하려는 동기**다. 다만 그림의 모든 점이 noise라고 판정한 것은 아니다. 실제 작은 움직임·낮은 대비·배경 변화도 포함될 수 있다. 이 예시는 문제를 보여주며 학습형의 우월성을 증명하지는 않는다.

그림에서 사람과 이벤트가 잘 보이도록 표시 영역을 잘랐으며, 이는 시각화용 GT bbox/관절 투영에 따른 crop이다. 제안 네트워크가 추론 때 GT crop을 입력받는다는 의미는 아니다.

### 양쪽 다리 전체

![골반 주변부터 양쪽 발까지 포함한 실제 네 누적 기간 비교](/home/namhj/EventPose/exp/261029/dynamic_aggregation_paper_figure/actual_legs_detail.png)

골반 주변부터 양쪽 발까지 `[351, 301, 589, 639]`, **238×338px 영역**을 사용한다. 종전의 44×135px 무릎~발목 ROI보다 면적을 약 **13.5배** 넓혔다. 주변 관측도 포함되므로 활성 픽셀 수를 다리의 정확한 정보량으로 해석하지 않는다.

원본 라벨의 약 30Hz 관절 궤적을 보간한 진단에서 사례 A의 200ms 평균 영상 이동거리는 양쪽 팔꿈치·손목 약 **106.10px**, 양쪽 hip/knee/ankle/foot 약 **3.68px**였다. 같은 시간창이 서로 다른 부위에서 다른 운동 범위를 포함한다는 실제 예시다. 이 값은 GT 기반 진단이며 모델이 예측한 운동량이 아니다. 한 시점의 결과로 데이터셋 전체 속도 분포를 대표하지 않는다.

## 5. 구조도의 네 단계

### 1단계: 입력 토큰화와 공간·시간 표현

현재 RGB를 ViT로 표현하고, 과거 이벤트를 서로 겹치지 않는 구간으로 나눠 patch token으로 만든다. 그림의 B3/B2/B1/B0는 각각 현재로부터 100–200/33–100/10–33/0–10ms 이전 구간이다. 실제 누적 수치의 차이로 각 구간을 분리해 그림에 사용했다.

시간 구간별 spatial Transformer는 가중치를 공유한다. 예시 설정은 256×256 입력, 8×8 patch, 32×32=1,024 tokens, D=192다. 이 수치는 구조 설계 후보이며 최적 설정을 확인한 결과가 아니다. gate 전에 모든 시간을 섞지 않고 각 token의 관측 기간·나이를 보존한다.

### 2단계: 신뢰도 학습

RGB 조건부 query와 이벤트의 공간·시간 문맥으로 관측의 사용 가중치를 학습한다. 현재 자세와의 관련성, 주변 관측과의 일관성, 나이를 함께 본다. 가중치는 실제 sensor noise 확률의 정답이 아니라 **학습된 집계 가중치**다.

패치별 Nmax와 최대 이력 Tmax는 후보량과 오래된 관측의 상한으로 둔다. N개를 채웠다는 이유로 모두 같은 가중치를 주지 않는다. noise burst가 후보 예산을 차지하는 경우에는 시간 구간별 예산을 나누는 대조군을 둔다.

### 3단계: 관절별 가중 cross-attention

22개 joint query가 시간별 이벤트 memory를 읽는다. 그림에서 제2단계는 **memory와 점수**를 전달하고, 신뢰도는 제3단계 attention logit에 한 번 적용한다. 같은 점수로 V를 미리 곱하고 logit에도 다시 곱하는 중복 적용은 기본안에 포함하지 않는다.

관측이 모두 불충분해도 softmax만 쓰면 어떤 이벤트를 반드시 고르게 된다. 따라서 **null token 또는 이전 상태를 읽는 선택**을 둔다. 관절 간 관계는 joint decoder에서 결합한다. RGB와 event의 카메라 차이는 보정·좌표 표현으로 다뤄야 하며, 같은 영상 픽셀에서 직접 대응한다고 가정하지 않는다.

### 4단계: 3D 자세 출력

pose head는 body22의 3D 위치를 출력하는 설계다. 학습 시 3D·속도·뼈 길이 손실을 적용한다. 그림 오른쪽 GT mesh는 출력 형식을 이해하기 위한 실제 데이터 참조일 뿐, 이 head가 mesh를 예측하거나 이미 이 결과를 냈다는 의미가 아니다.

## 6. 먼저 검증할 비교

같은 Transformer 용량·후보 관측·질의 시각에서 다음을 비교한다.

1. 고정 시간창, 패치별 최신 N개 관측, 균등 집계.
2. 관측 나이만으로 가중한 집계, 일반 cross-attention, 신뢰도 학습형 집계.
3. null token 제거/추가, 운동량 gate 추가, 정렬 제거/추가.
4. RGB-only 및 이전 상태만 사용하는 방법. 이벤트를 전부 무시하고도 얻는 이득인지 확인한다.

실제 자세·속도 오차와 관측 교란 시의 악화 정도로 판정한다. attention 그림이 그럴듯해진 것만으로 성공이라고 하지 않는다. 단순 count 기준선보다 낫지 않으면 학습형을 유지할 근거가 없다. 아직 이 비교의 새 학습 결과는 없다.

고정 count는 [DHP19](https://openaccess.thecvf.com/content_CVPRW_2019/papers/EventVision/Calabrese_DHP19_Dynamic_Vision_Sensor_3D_Human_Pose_Dataset_CVPRW_2019_paper.pdf), 공간별 시간창은 [ASTW](https://openaccess.thecvf.com/content/CVPR2026/html/Sui_Adaptive_Spatial-Temporal_Window_Unlocking_the_Potential_of_Event_Cameras_in_CVPR_2026_paper.html), 인체 motion과 이벤트 정렬은 [EvHuman](https://openaccess.thecvf.com/content/ICCV2025/papers/Wang_Continuous-Time_Human_Motion_Field_from_Event_Cameras_ICCV_2025_paper.pdf)와 겹친다. Transformer나 적응형 누적 자체를 최초 기여라고 주장하지 않는다.

## 7. 표시 규칙과 원본 검증

모든 새 이벤트 그림은 검정 배경, 고정 `sqrt(min(log1p(N)/log(9),1))` 밝기, 양극성 주황/빨강·음극성 cyan을 사용한다. 창끼리 공정하게 비교하기 위해 **동일한 약한 3×3 공간 지지 조건을 네 창 모두에 적용했다.** 이는 시각화 규칙이며 학습 입력·가중치를 변경한 것이 아니다.

여기서 N은 저장된 CSR 활성 관측 수다. 원시 이벤트별 발생 횟수·세부 시각을 복원한 것은 아니다. GT crop·mesh·도식 가중치와 실제 예측 결과를 구분했다. 원본 event/RGB/label은 읽기만 했으며 기존 GPU 작업을 변경하지 않았다.
