# 이벤트 기반 인체 동작 추정 연구 아이디어 개요

작성: 2026-10-26 · Idea agent의 약 30분 문헌 검토·짧은 실제 데이터 진단에 대한 연구 제안서.  
검토 기준: 실행 가능성, 최근 관련 연구와의 차이, 현재 저장 데이터에서 반증 가능한 실험.

**사용자 정정 반영:** 이 데이터셋에는 빠른 동작과 자연 blur가 많지 않다. 이를 주요 문제로 삼았던 초기 추천을 수정한다. 아래의 낮은 RGB 처리 예산 가설은 후속 제안이며 새 성능 검증 결과가 아니다.

**가장 먼저 할 것은 1번, 「관측 신뢰도에 조건화한 이벤트 기반 인체 동작 보정」이다.** 기존 RGB 모델·event encoder·보정·평가 코드를 활용하면서, 고정 융합 대비 조건부 신뢰도가 도움이 되는지만 작은 실험으로 분리할 수 있다. 단순히 이벤트를 더 넣는 실험은 이미 진행 중인 저장소의 RGB/event 비교와 겹치므로 독립 아이디어로 세지 않았다.

## 2. 현재 데이터에서는 blur보다 무엇을 연구할 것인가

**사용자 설명에 따르면 빠른 동작·자연 blur는 드물다. 그러므로 blur 강건성을 주목표로 추천했던 초기 판단은 수정한다.** 합성 blur를 주실험으로 만들면 데이터셋 본래의 문제보다 인위적인 열화에서만 유리한 방법이 될 위험이 있다. 합성 blur 예시는 보조 자료로만 남긴다.

현재 가장 실행할 만한 질문은 **정상 촬영에서 RGB 복원기를 드물게 실행해도, 중간 이벤트 갱신으로 동작 추정 품질을 유지할 수 있는가**다. 이는 곧바로 센서 latency 개선을 뜻하지 않는다. 우선 무거운 RGB 처리 비용과 모션 정확도의 관계를 검증한다.

| 목표 | 현재 우선순위 | 필요한 검증 |
|---|---|---|
| 자연 blur·초고속 동작 강건성 | 낮음. 데이터에 드물다는 사용자 설명 반영 | 별도 실제 데이터 없이는 주기여로 삼지 않음 |
| 낮은 RGB 처리 예산에서 자세·속도 품질 유지 | **가장 먼저 검증할 가설** | 동일 RGB 호출률의 RGB-only 예측·보간 기준선 대비 이벤트의 추가 가치 |
| 실제 end-to-end latency 개선 | 조건부 후속 목표 | 센서·전송·전처리·추론·출력까지 계측해야 함 |
| 저관측·정지 구간에서의 안정성과 재움직임 대응 | 보조 목표 | 실제 GT 지터 검수, 누적 drift와 움직임 시작 반응을 함께 평가 |

RGB를 적게 처리하면 RGB-only도 계산 비용을 줄일 수 있다. 따라서 2/5/10Hz 등 검증에서 정한 RGB 호출률마다 **같은 시각의 RGB만 사용하는 상태 유지·등속 예측·인과적 시간 모델**과 비교한다. 미래 RGB를 이용하는 보간은 별도의 비인과적 상한으로 둔다. 출력은 GT가 있는 공통 시각에서 비교하며 GT보다 촘촘한 출력의 정확도를 검증했다고 주장하지 않는다.

목표는 RGB 처리량만 줄이는 것이 아니라 **event 전처리와 보정까지 포함한 총 처리 비용에서 같은 품질을 더 싸게 얻는가**다. 이벤트 경로가 무거우면 호출 수가 줄어도 이득이 사라진다. 낮은 지연을 주장하려면 최신 출력의 p95 지연도 별도로 측정한다. 센서의 픽셀 지연과 시스템 지연은 다르다. [NIST의 센서 지연 측정 연구](https://www.nist.gov/publications/pixel-latency-measurements-event-cameras).

### 수정한 논문 메시지

> 정상적인 인체 동작에서 제한된 RGB 추론 예산을 사용할 때, 관측 신뢰도에 따른 이벤트 갱신은 RGB-only 시간 예측보다 3D 동작의 정확도와 반응성을 잘 유지하는가?

이벤트를 쓰기 좋은 상황을 억지로 만들기보다, 정상 데이터에서 실제 추가 정보가 있는지 확인한다. 정상 동작이 충분히 예측 가능하면 RGB-only가 이미 강할 수 있다. 현재 작은 선형 진단에서도 이벤트 추가의 일관된 이득은 없었다. 동일 예산의 강한 RGB-only 기준선을 못 넘으면 이 데이터만으로 이벤트의 필요성을 입증하기 어렵다는 결론을 받아들인다.

## 3. 이번에 실제로 확인한 데이터와 테스트

원본 `dataset/`은 `/mnt/nfs_L/etri_processed`를 가리킨다. 데이터와 모델 자산은 읽기 전용으로 사용했고 기존 GPU 학습에 손대지 않았다. 새로운 persistent Goal이나 장기 학습을 생성하지 않았다.

실제 split 스냅샷은 Train **220개 이름의 목록**, Test **64세션을 키로 하는 구간 사전**이다. 과거 보고서의 두 목록·219/64와 다르다. Train 이름 중 `20260720_142337_033318_202_i_203`은 현재 디렉터리에 없었다. 이번에 선택한 세션은 실제 읽기에 성공했고 Train에 포함되며 Test 키에는 없었다. 전체 피험자 분할의 적합성이나 향후 학습 데이터 준비까지 검증한 것은 아니다.

저장 이벤트는 960×720 CSR 희소 프레임의 활성 관측이다. 개별 원시 이벤트의 발생 시각·다중 발생 횟수는 복원하지 않았다. RGB/event를 같은 픽셀로 취급하지 않고, 보정된 타임스탬프와 각 카메라의 K/R/t를 사용했다. SMPL-X 빠른 관절 계산은 표준 full forward와 비교해 선택 표본에서 최대 차이가 0.00002m 미만임을 확인했다. 라벨 자체의 시간적 정확도와 지터는 후속 본실험 전에 따로 검수해야 한다.

### 테스트 A. 이벤트가 움직임과 연결되는가

Train 전신 6명·6세션에서 1~21초, 10Hz, 피험자당 200개 시점을 분석했다. 한 사람씩 제외한 선형 모션 진단은 1,188표본이다. 이벤트 관측 수와 관절 속도의 세션별 상관은 높았지만, 과거 자세·속도 회귀에 이벤트를 더했을 때 골반 정렬 관절 오차는 **27.74→28.68mm로 악화**했다. 절대 오차는 32.19→32.01mm로 약간 감소했다.

이 진단은 직전 두 GT 자세를 주는 oracle 1단계 예측이다. 실제 추적 정확도, 미세조정 모델 성능, blur 개선 결과와 구분한다. **현시점에서 단순 이벤트 추가의 일관된 3D 이득은 없다.** 자세·속도 prior가 강한 정상 구간에서 단순 특징을 추가하는 것만으로는 부족하다는 판단이다.

### 테스트 B. 긴 시간창은 관측을 더 좋게 만드는가

상체 2세션·전신 2세션의 원해상도 패치 진단에서 창이 길어질수록 활성 비율이 늘었다. 그러나 200ms 창의 전체 활성 픽셀 중 최근 10ms에는 재관측되지 않은 비율이 약 **85~92%**였다. 오래된 관측이 전부 잘못된 잔상이라는 뜻은 아니다. 현재 정보와 기억을 나누어 처리할 동기다.

### 테스트 C. 다른 시점이 관측을 보완하는가

한 전신 세션의 공통 4,023개 관절-시점에서 저관측 패치는 device0 약 0.025%, device1 8.799%, device2 0.224%였고, 세 시점 모두 저관측인 경우는 없었다. 다만 최선 시점 device0는 이미 대부분 활성이라 **강한 단일 시점 대비 추가 이득은 아직 작다.** 3D 정확도나 방향별 관측성을 테스트한 결과는 아니다.

### 테스트 D. latency 논점을 실제 구현에서 확인

CPU에서 메모리에 적재한 이벤트로 224×224 표현을 생성한 중앙값은 회색조 1.35ms, 33ms count 1.79ms, 100ms 3구간 5.21ms, 시간표면 38.36ms였다. 표현별 1회 워밍업 뒤 20개 시점을 측정했다. 원본 읽기·센서·HMR·GPU·전송은 제외했다. **센서가 빠르더라도 표현 생성에서 비용이 커질 수 있다.** 현재 NumPy 구현의 측정이며 최적화 구현의 한계가 아니다.

추가로 실제 RGB 2프레임에 15/31픽셀 수평 blur를 만들어 열화 대조 예시를 확인했다. 자연 blur 검출이나 자세 성능 평가는 수행하지 않았다. [합성 예시와 조건](/home/namhj/EventPose/exp/261026/idea_motion_probe/synthetic_blur_controls.jpg).

큰 관측 분석은 10개 session-view, 원해상도 추가 분석은 6개 session-view다. 서로 겹치는 데이터를 포함하므로 독립 표본 16개로 합치지 않았다. 이번 실제 읽기의 고유 세션은 전신 6개와 상체 2개다.

## 4. 관련 연구를 반영한 주제 선택

가장 중요한 신규성 점검은 [E-3DPSM, CVPR 2026](https://arxiv.org/abs/2604.08543)이다. 이미 delta/direct pose, covariance, Kalman 방식 결합을 갖추고 있다. 그러므로 “이벤트에 Kalman filter를 붙인다”는 아이디어는 제외했다. 원문에서 추론 시 공통 Q/R을 사용한다는 점을 확인하고, 1순위는 현재 관측 상태의 조건화와 그 유용성 검증으로 좁혔다.

2순위는 [ASTW, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Sui_Adaptive_Spatial-Temporal_Window_Unlocking_the_Potential_of_Event_Cameras_in_CVPR_2026_paper.html)와의 중복 위험이 크다. 인체 구조와 3D motion 목적이 일반 patch 적응보다 효과적이어야 한다. 3순위는 [UPose3D, ECCV 2024](https://arxiv.org/abs/2404.14634) 등 기존 uncertainty-aware multi-view 방법을 넘어 이벤트 운동 방향의 정보가 실제로 도움이 되는지를 보여야 한다.

각 연구의 더 자세한 차이와 링크는 세 개별 보고서에 있다. 제목·초록 수준의 겹침을 걸러낸 탐색이며 포괄적 신규성 검증이나 선행연구 부재의 보증은 아니다.

## 5. 추천 1순위의 논문 outline

1. **서론:** 평균 정확도만으로는 이벤트 효용이 드러나지 않는 이유. 제한된 RGB 호출 예산에서 중간 동작 관측이 필요한지, 이벤트 침묵에서 신뢰도가 어떻게 바뀌는지의 문제.
2. **관련 연구:** EventCap/EventHPE, 최근 state-machine motion, RGB/event fusion 및 RGB-only 시간 예측. 각 방법과의 좁은 차이.
3. **문제 정의:** 인과적 입력·공통 좌표·body22 출력, 관측 부재와 센서 부재, 지연 예산 및 불확실성의 의미.
4. **방법:** 동결 RGB 모델, 이벤트 운동 갱신, 관절별 관측 조건화 Q/R, 위치/속도 지도와 불확실성 보정. RGB 호출 정책은 후속 확장.
5. **실험:** 피험자 분리·검증 고정, 정상 구간의 RGB 호출률별 비용–정확도 비교, dropout과 시간 오프셋 보조 평가. 동일 호출률의 강한 RGB temporal 및 고정 Q/R 기준선.
6. **분석:** 정확도–지연 곡선, 관절별 신뢰도, risk–coverage, peak 속도·지터, 이벤트 교란 대조군과 실패 사례.
7. **한계와 결론:** 빠른 동작·blur가 드문 촬영 조건, GT 시간 해상도·고정 카메라·자동 라벨 품질·다중 인물 대응의 한계.

첫 실험에서는 모든 것을 함께 구현하지 않는다. **같은 낮은 RGB 호출률의 RGB-only 예측 대비 event 보정의 이득부터** 확인한다. 통과하면 고정 Q/R 대 관측 조건화 Q/R을 비교한다. 새 피험자·새 구간에서 정확도–총 비용 이득이 없으면 연구 가설을 수정한다. 센서 지연이나 초고속 GT가 필요한 주장으로 범위를 무리하게 넓히지 않는다.
