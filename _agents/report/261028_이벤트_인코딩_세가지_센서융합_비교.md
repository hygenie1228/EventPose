## 실제 Train coverage와 checkpoint 출처

분할 Train body 전체 유효 GT는 656,500프레임이다. 그중 최적화용51피험자·51세션은 유효GT 557,922프레임(기준 clock 560,305프레임), Train holdout9피험자·9세션은 유효GT 98,578프레임이다. 고정 학습 subset 6,501프레임은 전체 유효Train의0.9903%, 최적화용 유효GT의1.1652%다. 실제로 본 고유프레임 수와 성공 update는 위의 각 학습 행으로 따로 기록한다.
원본 released checkpoint는 original_pretrained_manifest.json의 실제 SHA로 동결했다. 모든 새 학습은 동일 원본에서 시작하며 이전 ETRI fine-tuned delta는 적재하지 않는다. 각 결과 checkpoint는 해당 조건 checkpoints/<조건>/best.pt이고, Train holdout으로 선택한다. best/last를 별도로 보존하며 최종 실제 CPU load·SHA·optimizer update 검증을 한다.

## 검증과 해석

첫 프레임 정렬은 정확한 frame0에서만 변환을 구해 구간 전체에 고정한다. frame-aligned는 매프레임 다시 계산한다. MPJPE는 pelvis 평행이동, PA-MPJPE는 반사 없는 proper Sim3다. 다섯 주지표는 같은 검출·공통 GT와 frame0 유효 표본을 사용하며 미검출을0오차로 넣지 않는다.
센서별 검출·좌표변환·매칭을 유지한다. event-only는 학습·검출·추론에 RGB 픽셀을 읽지 않는다. GTbox·pose·depth는 추론입력이 아니다.
전체11조건 완료 후 동일 GPU 순차 온라인/캐시 전체파이프라인 속도, 피험자 cluster bootstrap95%CI·Holm·효과크기와 동작속도별 결과를 추가한다. 12시간 내 미완료 항목은 그대로 미평가로 남기고 본인 작업만 checkpoint 보존 중단 후 Goal을 pause한다. 실제 개선을 보장하거나 결과를 만들지 않는다.
