# 지금까지의 분석과 실험 요약

2026-10-26 작성. 기존 보고서와 저장된 검증 기록을 기준으로 정리했다. 요약 작성 중 새 학습·평가를 실행하거나 데이터셋을 수정하지 않았다.

**현재 결론:** ETRI RGB 자세 추정에서는 미세조정 Multi-HMR이 가장 좋은 정확도를 보였다. 이벤트 추가의 성능 이득은 아직 확정하지 못했다. 별도 트랙2 실험에서도 현재 보고된 Multi-HMR 후보는 제공 기준 모델 init_v6를 넘지 못했다.

1. **데이터 구성 분석**
   서버 I는 254세션, 서버 L은 539세션이며 L의 283세션에 SMPL-X GT가 있다. L 자체에는 Depth 영상이 없고 공통 세션은 I의 Depth를 연결할 수 있다. 학습 219세션·68명과 Test 64세션·20명을 피험자 중복 없이 분리했고, 학습 내부는 187세션 학습/32세션 검증으로 나눴다.

2. **RGB 모델 학습·전체 Test 비교 완료**
   Multi-HMR 약 14시간 미세조정과 NLF의 head/후반부 학습 설정을 비교했다. Test 320개 10초 구간·96,124 RGB 프레임을 평가했으며 아래 자세 오차는 네 모델 공통 103,188 사람-프레임 기준이다. 오차는 모두 mm다.

| 모델 | first frame-aligned MPJPE (mm) | first frame-aligned PA-MPJPE (mm) | frame-aligned MPJPE (mm) | frame-aligned PA-MPJPE (mm) | Root absolute depth error (RPE-Z, mm) |
|---|---:|---:|---:|---:|---:|
| Multi-HMR 기본 | 159.62 | 145.95 | 95.14 | 58.28 | 241.38 |
| NLF 기본 | 116.71 | 111.75 | 79.08 | 53.41 | 90.65 |
| NLF 미세조정 | 142.10 | 145.52 | 90.68 | 62.20 | 96.61 |
| Multi-HMR 미세조정 | **68.69** | **73.37** | **46.85** | **32.63** | **44.38** |

다섯 번째 열은 **Root absolute depth error (RPE-Z)**로, 정렬하지 않은 카메라 좌표의 pelvis Z에 대해 `mean(|Z_pred − Z_GT|) × 1000`을 계산했다. 3D root position error인 `mean(||root_pred − root_GT||₂)`와 구분한다. 네 자세 지표와 **동일한 공통103,188명-프레임**을 사용했다. 저장된320구간 예측을 CPU로 전수 재집계했으며 새 학습·GPU 추론은 실행하지 않았다. 근거: `exp/261024/nlf_finetune_12h/root_depth_audit.json`.


첫 프레임 정렬은 정확한 frame0의 변환을 구간 전체에 고정하며, 프레임별 정렬은 매 프레임 다시 구한다. MPJPE는 골반 평행이동, PA는 proper Sim(3) 정렬이다. 체크포인트는 Train 내부 검증으로 선택했으며 Test로 선택하지 않았다. 두 Multi-HMR만 비교한 별도 보고서와는 공통 평가 표본이 달라 수치가 조금 다르다.

동일 GPU 순차 측정에서 Multi-HMR은 약 7.35~7.37fps, NLF는 약 3.84fps였다. 미세조정 Multi-HMR의 절대 MPJPE는 70.85mm, GT 매칭률은 98.723%였다. 다만 시간적 가속도 오차는 기본 Multi-HMR이 더 낮았다. NLF는 이번 학습으로 Test 자세 오차가 오히려 커졌다. 원시 결과 1,280개 재집계와 보고서 대조는 `final_audit.json`에서 통과했다.

3. **이벤트 표현 분석 완료**
   상체·전신 두 장면에서 총 12가지 설정을 시각 비교했다. 33ms 극성 분리 누적은 현재 윤곽, 20ms 감쇠 시간표면은 최근 움직임, 100ms의 3구간 표현은 동작 순서를 보기 좋았다. 200ms 단일 누적은 빠른 팔 동작에 잔상이 컸다. 이는 시각적 관찰이며 자세 추정 정확도 순위는 아니다.

4. **RGB·이벤트 입력 검증 및 확장 실험**
   device0 전체 283세션의 타임스탬프·보정·매핑을 검사했고 캐시 283세션 완료를 기록했다. RGB/event 카메라 위치 차이는 약 47.17mm이므로 같은 픽셀로 취급하지 않는다. 저장 event는 희소 프레임 표현으로, 원시 이벤트별 시각·횟수를 복원할 수 없다. 누적 33ms, 3구간 100ms, 시간표면, 회색조의 네 인코딩을 마련했다. RGB 기준선과 융합 조건의 학습 기록은 있으나 10조건 전체 최종 비교는 미완료이며, 10월 25일 사용자 요청에 따른 중단 기록이 있다. 이벤트의 정확도·속도 개선을 아직 주장할 수 없다.

5. **별도 트랙2 Multi-HMR 미세조정·오류 분석**
   30개 영상의 Train20/Test10 분리에서 전체 RGB·고정 crop·head 및 backbone 학습을 비교했다. 대상 마스크 확장이 배경 사람 선택을 허용하는 오류를 실제 재추론으로 확인했고, 원본 마스크 내 머리 위치와 몸 영역 일치 검사를 추가했다. 10월 26일 05:47 UTC 보고서에서 전체 Test를 마친 후보 중 최저 CD-H는 14.9887cm로 init_v6의 12.4260cm보다 높다. 추가 표면 감독 후보는 해당 표에서 평가 대기다. 이동 궤적과 자세 오차는 SMPL-X→MHR 변환 전부터 존재해 변환만으로 격차를 설명할 수 없다. 이 트랙의 CD-H·ACC-H는 위 ETRI 관절 지표와 직접 비교하지 않는다.

**남은 일:** RGB/event 전체 조건의 최종 Test·동일 GPU 속도·통계 비교, 트랙2 추가 후보 평가와 최종 저장 결과 검증이다. 완료된 RGB 비교와 진행 중인 확장 실험을 구분해 해석해야 한다.
